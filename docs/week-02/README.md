## 概念速查

一行一个概念：定义与公式压缩自本周讲义，公式为纯文本写法；点"详见"直达对应讲次。

| 概念 | 关键定义 | 公式 / 数量关系 | 详见 |
| ---- | -------- | -------------- | ---- |
| N-gram 语言模型 | 给定历史，输出下一个 Token 的概率分布，等价地为整段序列赋概率；只保留最近 n-1 个历史（unigram / bigram / trigram 分别看 0 / 1 / 2 个） | 精确链式法则 `P(w1...wT) = Π P(wi \| w1...w(i-1))`；未平滑 MLE `P(w\|h) = C(h,w) / C(h)` | [Day 008](day-008.md) |
| 句子边界与数值计算 | 左侧补 n-1 个 `<s>`，右侧预测一个 `</s>`，整句概率必须包含结束事件；对数把连乘变成相加，避免长序列下溢 | — | [Day 008](day-008.md) |
| 三类未知 | OOV：Token 不在词表 → `<UNK>`/子词/字节方案；未见 N-gram：Token 已知但组合未见 → 平滑；未见上下文：C(h)=0 → 回退、插值或明确兜底 | 可能的组合随阶数指数增长，有限训练集必然留下大量零计数 | [Day 009](day-009.md) |
| 加 k 平滑 | 所有计数统一加 k 再归一化；简单、非零、归一化，但大词表下概率分配通常不够精细 | `P(w\|h) = [C(h,w)+k] / [C(h)+k·\|V\|]` | [Day 009](day-009.md) |
| 经验交叉熵 | 测试集上的平均负对数似然；N 是实际参与计分的 next-token 事件数（PAD、-100 等忽略位置不进分母） | `H = NLL / N`，其中 `NLL = -Σ log_b Q(w_i\|h_i)` | [Day 010](day-010.md) |
| 困惑度 | 正确 Token 逆概率的几何平均；正确聚合是先汇总 loss 总和再除以有效 Token 数，不要等权平均句子 PP 或 batch mean | `PP = b^H = (Π 1/q_i)^(1/N)` | [Day 010](day-010.md) |
| 词袋（BoW） | 文档 → 词表维度上的计数向量；保留多重集计数，丢弃顺序（两句词同序不同则向量相同） | — | [Day 011](day-011.md) |
| TF 三种变体 | 原始计数：线性增长，可被堆词攻击；相对频率 tf/len(d)：长度归一化；对数饱和 1+ln(tf)：次线性增长，BM25 的思想前身 | — | [Day 011](day-011.md) |
| TF-IDF | 局部证据 × 全局区分度；是排序分数，不是概率；df 是包含该词的文档篇数，不是出现次数 | `w(t,d) = tf(t,d) × idf(t)`；`idf(t) = ln(N / df(t))` | [Day 011](day-011.md) |
| 余弦排序 | 分子 = 匹配词加权求和；分母 = 长度归一，无关的强特征会稀释分数 | `cos(q,d) = (q·d) / (\|q\|\|d\|)` | [Day 011](day-011.md) |
| 熵 / 交叉熵 / KL 散度 | 熵 = 描述 P 自身的平均最优码长（不确定性）；交叉熵 = 数据来自 P、用按 Q 设计的码本编码的平均代价；KL 衡量两分布差距且不对称 | `H(P,Q) = H(P) + D(P\|Q)`；`D(P\|Q) = Σ P(x) log2[P(x)/Q(x)]` | [Day 012](day-012.md) |
| BM25 | 次线性 TF 饱和 + 显式相对长度归一 + 恒正 IDF；分数是概率检索框架的 RSV 排序序数：不是概率、不跨查询/索引比较 | `BM25(q,d) = Σ_t idf(t) · tf·(k1+1) / (tf + k1·(1-b+b·\|d\|/avgdl))` | [Day 013](day-013.md) |
| 检索评价 | Recall@K 看覆盖，MRR 看首命中（未命中记 0）；优化前先做失效归因 | `Recall@K = \|top-K ∩ R\| / \|R\|`；`MRR = mean(1/首个相关排名)` | [Day 014](day-014.md) |

## 横向对比

### 平滑三法（Day 009）

| 方法 | 思路 | 要点 |
| ---- | ---- | ---- |
| 加 k 平滑 | 所有计数统一加 k | 简单、非零、归一化；大词表下分配不够精细 |
| 插值 | 高阶与低阶分布始终共同参与 | 权重在开发集上调 |
| 回退 | 高阶证据不足时退到低阶 | 必须配合折扣和归一化权重 |

Kneser–Ney 直觉：低阶概率不只看"出现多少次"，还看"在多少种不同上下文中出现"。

### 交叉熵家族换算（Day 010、012）

| 关系 | 含义 |
| ---- | ---- |
| `H = NLL / N` | 经验交叉熵 = 平均负对数似然 |
| `PP = b^H` | 困惑度 = 逆概率的几何平均 |
| `H(P,Q) = H(P) + D(P\|Q)` | 固定测试集 → H(P) 是常数：比较交叉熵 = 比较 KL |
| `H(P,Q) ≥ H(P)` | 熵是地板，完美模型得分 = 熵，不是 0 |
| `P(x)>0 而 Q(x)=0` | 交叉熵与困惑度 = +∞，这是平滑的真正理由 |

### idf 变体（Day 011）

| 变体 | 公式 | 性质 |
| ---- | ---- | ---- |
| 经典 | `ln(N / df)` | df=N → 权重 0（无区分度）；df=0 → 未定义 |
| 概率式 | `ln((N-df+0.5)/(df+0.5))` | BM25 使用，可为负 |
| 平滑式 | `ln((1+N)/(1+df)) + 1` | sklearn 默认，恒 ≥ 1 |

本语料实测：经典 → 平滑 IDF 会使排名反转；公式、变体、归一化必须随结果一起报告。

### TF-IDF 余弦 vs BM25（Day 011、013）

| 维度 | TF-IDF 余弦（经典） | BM25 |
| ---- | -------------------- | ---- |
| TF | 线性增长，可被堆词攻击（实测 8 倍堆砌 = 8 倍分数） | 次线性饱和，上限 `idf·(k1+1)`；tf=k1 恰好半饱和（实测 8 倍堆砌约 1.68 倍） |
| 长度归一 | 余弦的范数归一（隐式） | 显式相对长度 `\|d\|/avgdl`；b=0 不归一，b=1 全归一，默认 0.75 留缓冲 |
| IDF | 经典 `ln(N/df)`（df=N → 0） | 恒正变体 `ln((N-df+0.5)/(df+0.5)+1)`（Lucene 形式，避免负值） |
| 分数含义 | 相似度，用于排序 | 概率检索框架（双泊松模型）的 RSV 排序序数：不是概率、不跨查询/索引比较 |
| 极端参数 | — | k1=0 二值命中；k1→∞ 退回线性 TF-IDF |

两者都治不了词汇鸿沟（同义词不同维度）→ 后续靠改写、同义词或混合检索。
