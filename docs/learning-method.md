# 每日学习方法

每天只处理一个技术细节，建议用时 60–90 分钟。

每日页面中的完整讲义是主学习材料。原始教材、论文和标准主要用于我撰写讲义时交叉核对，也保留给你在产生疑问时查证；除非当天特别标注，否则不要求在规划时间内通读原始资料。

## 1. 概念与定义（15 分钟）

- 它是什么？
- 它解决什么问题？
- 它与容易混淆的概念有什么区别？

不要只记比喻，需要写出尽可能严格的定义。

## 2. 关键原理（15 分钟）

- 输入是什么？
- 中间经历了哪些处理？
- 输出是什么？
- 哪些参数或假设决定结果？

尝试把整个过程画成一条数据流。

## 3. 代码实验（30 分钟）

按照下面的顺序练习：

1. **运行**：先让最小代码正确工作。
2. **追踪**：标注数据类型、张量形状与每个变量的含义。
3. **修改**：只改变一个变量，并在运行前预测结果。
4. **重写**：不看答案，独立完成核心函数。

## 4. 笔记与反思（15 分钟）

重点记录：

- 我原来怎么理解？
- 现在的严格定义是什么？
- 哪次实验改变了我的理解？
- 我之前错在哪里？
- 还有什么具体问题没有解决？

笔记不是课程内容的摘要，而是自己理解发生变化的记录。
