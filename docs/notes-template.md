# 每日笔记模板

复制下面的结构，完成当天笔记。

```markdown
# Day XXX：知识点名称

## 1. 我原来怎么理解

## 2. 现在的严格定义

## 3. 输入—处理—输出

## 4. 关键代码与数据变化

## 5. 修改实验

### 我的预测

### 实际结果

### 原因解释

## 6. 我之前理解错了什么

## 7. 仍然不理解的问题
```

## 提交前检查

- [ ] 没有大段复制学习资料。
- [ ] 用自己的话解释了核心概念。
- [ ] 记录了真实的代码输出。
- [ ] 至少修改了一次输入或参数。
- [ ] 对实验结果给出了原因解释。
- [ ] 提出了具体、可以回答的问题。
