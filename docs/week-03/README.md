## 概念速查

一行一个概念：定义与公式压缩自本周讲义，公式为纯文本写法；点"详见"直达对应讲次。

| 概念 | 关键定义 | 公式 / 数量关系 | 详见 |
| ---- | -------- | -------------- | ---- |
| 分布式假设 | 上下文相似的词，语义相似（Harris 1954 / Firth 1957）；语义可以从"分布"里统计出来 | — | [Day 015](day-015.md) |
| 上下文分布与余弦 | 语料 → 滑动窗口 → 词—上下文矩阵 M[w,c]，每行 = 一个词的稀疏向量；余弦度量"分布重叠"，不是"是否共现" | one-hot：任意两词 cos = 0（词汇鸿沟的几何本质） | [Day 015](day-015.md) |
| PPMI | 按"超出偶然的倍数"给共现加权，与 TF-IDF 精神相通 | `PPMI = max(0, log2[P(w,c) / (P(w)·P(c))])` | [Day 015](day-015.md) |
| Embedding | 映射 E: V → R^d，d ≪ \|V\|（典型 100–300）；三种等价视角：查表 / 矩阵的行 / one-hot × 矩阵 | — | [Day 015](day-015.md) |
| Skip-gram 训练目标 | 用中心词预测窗口内上下文；最小化损失 = 最大似然；相似是涌现结果，不是直接监督 | `P(o\|c) = exp(u_o·v_c) / Σ exp(u_w·v_c)`；`J = -u_o·v_c + log Σ exp(u_w·v_c)`；初始 loss = ln\|V\| | [Day 016](day-016.md) |
| softmax 与交叉熵 | softmax 指数放大差异、平移不变；两类 softmax = sigmoid；温度 T 改变尖锐度 | `softmax(z)_i = exp(z_i) / Σ exp(z_k)`；`L = -z_y + log Σ exp(z_k)` | [Day 019](day-019.md) |
| 核心梯度 | 预测减目标：对了且自信 → 梯度自动归零；错了且自信 → 修正最强；Embedding 查表只更新被查到的行 | `∂L/∂z_i = p_i - y_i`；到参数 `∂L/∂w_i = (p_i - y_i)·x`（外积） | [Day 019](day-019.md) |
| 数值稳定（log-sum-exp） | 先减 z_max 再取 exp，避免溢出；框架 CrossEntropyLoss 吃 logits 的原因 | `log Σ e^z = z_max + log Σ e^(z - z_max)` | [Day 019](day-019.md) |
| 样本构造 | Skip-gram 逐位置配对：边界裁剪不补 PAD、句子独立不跨句、重复保留（训练对多重集 ≡ 共现计数矩阵）；动态窗口近邻更受重视；高频词下采样同时丢弃中心与上下文角色 | 距离 k 的期望权重 = `(m-k+1)/m`；`P_discard(w) = 1 - sqrt(t / f(w))`，f < t 时为 0 | [Day 017](day-017.md) |
| CBOW 样本 | 每位置 1 个样本：上下文袋（无序、可重复）向量平均 → 预测中心词 | 同句实测：Skip-gram 14 对 vs CBOW 5 个样本 | [Day 017](day-017.md) |
| 负采样（SGNS） | 多分类 → 1 正例 + k 个负例的二分类；梯度系数 σ(s) - y：正例拉、负例推；每对只更新 k+1 个向量 | `J = -log σ(u_o·v_c) - Σ log σ(-u_w̄i·v_c)`；初始 loss = (k+1)·ln2；负例分布 `P_n(w) ∝ count(w)^0.75` | [Day 018](day-018.md) |
| 静态 vs 上下文表示 | 静态一词型一向量、天花板是多义混合；上下文 v(w,s) 依赖整句；Embedding 层仍是静态查表，上下化发生在其上的网络层 | 玩具上下化：`v = v_static(w) + α·mean(v_static(邻居))`（α=2.0 实测：两个"苹果"余弦 0.4706，静态自比 = 1） | [Day 020](day-020.md) |
| 词向量训练与评价 | loss ≠ 向量质量（训练过头 loss 反弹而几何不变 → 早停是真实需要）；指标饱和与种子波动：单种子消融不可信 | 类间隔 = 类内均 cos − 跨类均 cos；top-2 近邻纯度（基线实测：纯度 1.0，类内 0.9919 vs 跨类 0.3022） | [Day 021](day-021.md) |

## 横向对比

### Skip-gram vs CBOW（Day 016、017）

| 维度 | Skip-gram | CBOW |
| ---- | --------- | ---- |
| 预测方向 | 中心词 → 窗口内每个上下文 | 上下文袋平均 → 中心词 |
| 样本数量 | 每位置约 2m 对（同句 m=2 实测 14 对） | 每位置 1 个样本（同句 5 个） |
| 特点 | 训练慢；对稀有词友好 | 快且平滑 |

### full softmax vs 负采样（Day 016、018）

| 维度 | full softmax | 负采样（SGNS） |
| ---- | ------------ | -------------- |
| 每对开销 | \|V\| 次点积 + 全表更新（分母牵动每个 p_w） | 每对只更新 k+1 个向量 |
| 自检初值 | loss = ln\|V\|（实测 ln 8 = 2.0794） | loss = (k+1)·ln2（实测 3ln2） |
| 优化目标 | softmax 交叉熵最大似然（Day 012） | 不是 softmax 的近似，是另一个目标（NCE 血统）；分数未归一化，σ(u·v) 不是条件概率 |
| 隐式联系 | — | 隐式分解 PMI - log k 矩阵（连 Day 015 计数式） |
| 现代回响 | — | 正例拉近 + 负例推远 = 对比学习；InfoNCE ≈ softmax 归一化的负采样 |

### 静态表示 vs 上下文表示（Day 020）

| 维度 | 静态（Word2Vec / GloVe / fastText） | 上下文（ELMo / BERT / 现代 LLM） |
| ---- | ----------------------------------- | -------------------------------- |
| 向量 | 一词型一向量，查表 O(1) | v(w,s) 依赖整句，同词不同句不同向量 |
| 多义词 | 两个义项的上下文合并，训练再好也只是"更准的混合" | 近邻随句子翻转（实测：水果义 → 香蕉 0.686 > 小米 0.172；公司义 → 小米 0.515 > 香蕉 0.343） |
| 分工 | 词级特征、低延迟、Embedding 底座、fastText 子词 OOV | 消歧、句级语义、检索编码 |

注意：两类向量不在同一空间，不能放进同一个索引比较；BERT 用哪一层是超参数。

### 计数式 vs 预测式（Day 015、016、018）

| 路线 | 做法 | 代表 |
| ---- | ---- | ---- |
| 计数式 | 词—上下文共现矩阵 + PPMI 加权 + 余弦找近邻，维度 = \|V\| | Day 015 计数流水线 |
| 预测式 | 直接学 \|V\|×d 的 Embedding 表，共现统计只作训练信号 | Word2Vec（Day 016–018） |

两条路线信号相同（都是共现统计）；SGNS 隐式分解 PMI - log k 矩阵，说明二者殊途同归。
