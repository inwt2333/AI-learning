## 1. 从计数到预测：换一种利用共现的方式

Day 015 的路线是**计数式**：统计词—上下文矩阵，PPMI 加权，再（可选）SVD 降维。它有两个工程痛点：

* 矩阵是 $$|V|\times|V|$$：5 万词的词表就要 25 亿个单元，哪怕稀疏存储，统计与分解都沉重；
* 想改进（换窗口、换加权）就要重算整个矩阵。

Word2Vec 的路线是**预测式**（predictive）：不存矩阵，直接初始化一张 $$|V|\times d$$ 的小表（$$d\ll|V|$$），定义一个"用这张表预测共现"的目标函数，用梯度下降学出表里的每个数。两种路线利用的都是同一个信号——共现统计（Day 015 的分布式假设），差别只在"用统计直接构造"还是"用统计当监督信号"。

## 2. Skip-gram：用中心词预测上下文

Skip-gram 的设定：扫过语料的每个位置，取该词为**中心词**（center word），窗口内的其他词是它的**上下文**（context words）。训练目标是：**好的词向量，应该让真实的上下文在条件分布里获得高概率**。

完整数据流：

```
语料（已分词）
  → 滑动窗口枚举训练对 (中心词 c, 上下文词 o)
  → 用两套向量打分：logit = u_o · v_c
  → softmax 归一化成 P(o | c)（分母遍历全词表）
  → 单对损失 = -log P(o | c)
  → 求梯度，SGD 同时更新 v_c 和全部 u_w
  → 重复整个语料多轮，直到损失收敛
```

## 3. 训练目标的完整公式

对语料 $$w_1,\ldots,w_T$$、窗口 $$m$$，Skip-gram 最大化所有真实共现的联合概率：

$$
L=\prod_{t=1}^{T}\;\prod_{-m\le j\le m,\;j\ne0}P(w_{t+j}\mid w_t)
$$

取负对数得到损失函数（乘积变求和）：

$$
J=-\sum_{t}\sum_{j\ne0}\log P(w_{t+j}\mid w_t)
$$

条件概率用 softmax 定义：

$$
P(o\mid c)=\frac{\exp(\mathbf{u}_o^{\top}\mathbf{v}_c)}
{\sum_{w\in V}\exp(\mathbf{u}_w^{\top}\mathbf{v}_c)}
$$

符号约定（后面所有推导都用它们）：

* $$\mathbf{v}_c\in\mathbb{R}^d$$：词 $$c$$ 作**中心词**时用的向量（输入表的一行）；
* $$\mathbf{u}_o\in\mathbb{R}^d$$：词 $$o$$ 作**上下文**时用的向量（输出表的一行）；
* 每个词因此有**两套向量**：它在"被预测什么"和"预测别人"两个角色里的用法不必相同。训练结束后通常只保留 $$\mathbf{v}$$ 表（或取 $$(\mathbf{v}+\mathbf{u})/2$$）作为词向量。

**这不是语言模型**。Day 008 的语言模型预测"下一个 Token"，有方向、有链式概率；Skip-gram 预测"窗口内任意位置的词"，无序、逐对独立。混淆二者是面试常见错误。

## 4. 单对损失细读：它就是 Day 012 的交叉熵

把一对 $$(c,o)$$ 的损失单独写开：

$$
J_{(c,o)}=-\mathbf{u}_o^{\top}\mathbf{v}_c
+\log\sum_{w\in V}\exp(\mathbf{u}_w^{\top}\mathbf{v}_c)
$$

两部分各有含义：第一项是"真实上下文的得分"，越大损失越小；第二项 $$\log\operatorname{sumexp}$$ 是归一化代价，负责把得分变成合法概率。

三个连接点：

* **与 Day 012**：这就是"单类正确"的交叉熵——把 $$\mathbf{u}_w^{\top}\mathbf{v}_c$$ 看作 logits，$$-\log P(o\mid c)$$ 正是 softmax 交叉熵在真实类 $$o$$ 上的损失。最小化它 = 最大化这对的似然；在整个语料上做，就是最大似然估计；
* **初始 loss 有理论值**：向量全零（或近似零）时所有 logits 相同，$$P(o\mid c)=1/|V|$$，单对损失 $$=\ln|V|$$（自然对数时）。本节实验词表 8 个词，实测初始 loss 为 2.0794，而 $$\ln 8=2.0794$$——分毫不差，这是检查训练代码是否写对的第一道关卡；
* **分母是瓶颈**：$$\sum_{w\in V}$$ 遍历全词表。本实验只有 8 个词无所谓；真实词表 5 万时，**一个训练对**就要算 5 万个点积，更新还牵动全部 $$\mathbf{u}_w$$。这个瓶颈正是 Day 018 负采样要解决的。

## 5. 梯度：拉向与推离

对单对损失求导（$$\mathbb{1}$$ 为指示函数）：

$$
\frac{\partial J_{(c,o)}}{\partial\mathbf{u}_w}
=\left(P(w\mid c)-\mathbb{1}[w=o]\right)\mathbf{v}_c
$$

$$
\frac{\partial J_{(c,o)}}{\partial\mathbf{v}_c}
=\sum_{w\in V}\left(P(w\mid c)-\mathbb{1}[w=o]\right)\mathbf{u}_w
$$

读法比推导更重要——梯度下降（减去梯度）的效果是：

* **真实上下文 $$o$$**：系数 $$P(o\mid c)-1<0$$，更新把 $$\mathbf{u}_o$$ 和 $$\mathbf{v}_c$$ 往**互相靠近**的方向拉（点积变大）；
* **其他所有词 $$w$$**：系数 $$P(w\mid c)>0$$，被从 $$\mathbf{v}_c$$ 身边**推远**（点积变小），推力大小恰好等于模型当前分配给它的概率。

于是"训练"可以被一句话概括：**反复地，把真实共现的向量拉近，把模型误以为会共现的向量推开**。语义相似（Day 015 的"共享上下文"）不是被直接优化的目标，而是这个推拉过程的**涌现结果**：上下文分布相近的词，被同一批上下文向量以相近的方式拉扯，最终落在相近的位置。

softmax 交叉熵梯度的完整推导与数值稳定细节（log-sum-exp）是 Day 019 的主题；本节先用手写梯度把目标函数做实。

## 6. Python 实现：在 Day 015 语料上训练一次

只用标准库，把第 3–5 节的公式逐行落实。语料沿用 Day 015（"自然语言"与"机器学习"出现在相同句型里）：

```python
from math import exp, log
from random import seed, uniform

corpus = [
    ["我", "喜欢", "自然语言"],
    ["我", "喜欢", "机器学习"],
    ["自然语言", "很", "有趣"],
    ["机器学习", "很", "有趣"],
    ["我", "研究", "自然语言"],
    ["我", "学习", "机器学习"],
]


def build_pairs(corpus, window=1):
    """枚举 Skip-gram 训练对 (中心词, 上下文词)。

    输入：分好词的句子列表；window=1 表示左右各看 1 个词。
    返回：二元组列表。窗口内除中心词外的每个词都与中心词配一次对，
          且顺序对称：(我, 喜欢) 与 (喜欢, 我) 都会出现。
    """
    pairs = []
    for sentence in corpus:
        for i, center in enumerate(sentence):
            # 窗口范围 [i-window, i+window]，max/min 防止越界。
            for j in range(max(0, i - window), min(len(sentence), i + window + 1)):
                if i != j:
                    pairs.append((center, sentence[j]))
    return pairs


pairs_raw = build_pairs(corpus)
vocab = sorted({token for sentence in corpus for token in sentence})
word_to_id = {w: i for i, w in enumerate(vocab)}
V, d = len(vocab), 2  # 词表 8 个词；教学用 2 维向量
pairs = [(word_to_id[c], word_to_id[o]) for c, o in pairs_raw]
print(f"词表 |V| = {V}，训练对数量 = {len(pairs)}")
print("前 6 个训练对：", pairs_raw[:6])
```

输出：

```
词表 |V| = 8，训练对数量 = 24
前 6 个训练对： [('我', '喜欢'), ('喜欢', '我'), ('喜欢', '自然语言'), ('自然语言', '喜欢'), ('我', '喜欢'), ('喜欢', '我')]
```

24 个训练对，恰好等于 Day 015 共现矩阵的总计数——**训练对流就是矩阵的稀疏表示**，这是计数式与预测式在数据层面的等价起点。

训练循环（手写梯度、SGD、log-sum-exp 稳定化）：

```python
seed(42)  # 固定随机种子，结果可复现

init_scale = 0.1
# 两套向量表：vec_in 是 v（作中心词），vec_out 是 u（作上下文）。
# 初始化成很小的随机数——全零会让所有 logits 相同、梯度失去方向。
vec_in = [[uniform(-init_scale, init_scale) for _ in range(d)] for _ in range(V)]
vec_out = [[uniform(-init_scale, init_scale) for _ in range(d)] for _ in range(V)]

lr, epochs = 0.02, 150
for epoch in range(epochs):
    total_loss = 0.0
    for c, o in pairs:  # 逐对处理：每对独立算损失、独立更新
        vc = vec_in[c]
        # ① 打分：全词表的 logit = u_w · v_c
        logits = [sum(uw[k] * vc[k] for k in range(d)) for uw in vec_out]
        # ② log-sum-exp 稳定算 log 概率：先减去最大值再 exp，防止溢出。
        m = max(logits)
        log_z = m + log(sum(exp(x - m) for x in logits))
        log_probs = [x - log_z for x in logits]
        total_loss -= log_probs[o]
        probs = [exp(lp) for lp in log_probs]
        # ③ 更新全部 u_w：系数 (P(w|c) - [w==o])，即“真实拉、其余推”。
        for w in range(V):
            g = probs[w] - (1.0 if w == o else 0.0)
            for k in range(d):
                vec_out[w][k] -= lr * g * vc[k]
        # ④ 更新 v_c：对全词表的 u 加权求和作为梯度。
        grad_c = [0.0] * d
        for w in range(V):
            g = probs[w] - (1.0 if w == o else 0.0)
            for k in range(d):
                grad_c[k] += g * vec_out[w][k]
        for k in range(d):
            vc[k] -= lr * grad_c[k]
    if epoch % 30 == 0 or epoch == epochs - 1:
        print(f"epoch {epoch:>3}: 平均 loss = {total_loss / len(pairs):.6f}")
```

输出：

```
epoch   0: 平均 loss = 2.079427
epoch  30: 平均 loss = 2.056132
epoch  60: 平均 loss = 1.792423
epoch  90: 平均 loss = 1.439213
epoch  120: 平均 loss = 1.246883
epoch 149: 平均 loss = 1.135669
```

起点 2.079427 与 $$\ln8=2.079442$$ 吻合到小数点后四位（微小偏差来自小随机初始化）。loss 平缓起步、中段加速、后期放缓，是这类小语料训练的典型形状。

训练完的表拿来检查——先看条件概率，再看向量近邻：

```python
def cond_prob(context, center):
    """训练后的模型：P(上下文 | 中心词)，按第 3 节公式计算。"""
    vc = vec_in[word_to_id[center]]
    logits = [sum(uw[k] * vc[k] for k in range(d)) for uw in vec_out]
    m = max(logits)
    log_z = m + log(sum(exp(x - m) for x in logits))
    return exp(logits[word_to_id[context]] - log_z)


for ctx, ctr in (("喜欢", "自然语言"), ("很", "自然语言"),
                 ("研究", "自然语言"), ("机器学习", "自然语言")):
    print(f"P({ctx} | {ctr}) = {cond_prob(ctx, ctr):.4f}")


def cos(a, b):
    na = sum(x * x for x in a) ** 0.5
    nb = sum(x * x for x in b) ** 0.5
    return sum(x * y for x, y in zip(a, b)) / (na * nb)


target = word_to_id["自然语言"]
scored = sorted(
    ((cos(vec_in[target], vec_in[i]), w)
     for i, w in enumerate(vocab) if w != "自然语言"),
    reverse=True,
)
for score, w in scored:
    print(f"cos(自然语言, {w}) = {score:.4f}")
```

输出：

```
P(喜欢 | 自然语言) = 0.3004
P(很 | 自然语言) = 0.3428
P(研究 | 自然语言) = 0.1736
P(机器学习 | 自然语言) = 0.0028

cos(自然语言, 机器学习) = 0.9999
cos(自然语言, 我) = 0.7587
cos(自然语言, 有趣) = 0.7146
cos(自然语言, 很) = -0.6369
cos(自然语言, 研究) = -0.9637
cos(自然语言, 学习) = -0.9843
cos(自然语言, 喜欢) = -0.9858
```

## 7. 结果解读：预测的是上下文，相似来自分布

**第一组数字**：模型学会了"自然语言"的真实上下文——$$P(\text{喜欢}\mid\text{自然语言})=0.3004$$、$$P(\text{很})=0.3428$$、$$P(\text{研究})=0.1736$$，三者合计约 0.82，而 $$P(\text{机器学习}\mid\text{自然语言})$$ 只有 0.0028。**"机器学习"从未出现在"自然语言"的窗口里，模型正确地学到了这一点**——它预测的是上下文，不是同义词。

**第二组数字**：尽管互不为上下文，$$\cos(\mathbf{v}_{\text{自然语言}},\mathbf{v}_{\text{机器学习}})=0.9999$$。相似不是被直接优化的，而是涌现的：两个词被同一批上下文向量（喜欢、很）以同样方式拉扯，又同样不被其余词的推力青睐，最终走到一起。**Day 015 用计数得到的核心事实（共现分布重叠 ⇒ 语义相近），在学习范式下被完整复现**。

**必须诚实声明的退化**：其余词的余弦是 -0.64 到 -0.99 的大负值，这不是"反义"。$$d=2$$ 太小，8 个向量在平面上几乎被挤到一条直线附近（余弦大小普遍接近 ±1），几何已经退化。真实词向量用 100–300 维，余弦分布会健康得多。这个现象本身是个教训：**维度过低时，余弦的绝对值失去含义，只能看排序**。

## 8. CBOW：目标的对偶形式

CBOW（Continuous Bag-of-Words）把方向反过来：用**上下文预测中心词**。把窗口内上下文的 $$\mathbf{v}$$ 向量平均成一个组合向量

$$
\mathbf{h}=\frac{1}{2m}\sum_{-m\le j\le m,\;j\ne0}\mathbf{v}_{w_{t+j}}
$$

再对全词表 softmax，最大化 $$P(w_t\mid\text{上下文})$$：

$$
P(c\mid\text{context})=\frac{\exp(\mathbf{u}_c^{\top}\mathbf{h})}
{\sum_{w\in V}\exp(\mathbf{u}_w^{\top}\mathbf{h})}
$$

分工上的经验结论：

* **Skip-gram** 逐对训练，一个低频词每次当中心词都能生成一整窗训练对，对**稀有词更友好**；训练对多，更慢；
* **CBOW** 把窗口平均成一个预测，天然平滑掉噪声，**更快**，对高频常见词效果稳定；对稀有词证据不足。

负采样等优化对两者都适用（Day 018）。样本构造的具体差异（窗口内怎样配对、下采样高频词）统一在 Day 017 展开。

## 9. 计算瓶颈与工程权衡

* **分母的代价**：每个训练对要对全词表算点积与 softmax（$$O(|V|d)$$），还要更新全部 $$\mathbf{u}_w$$。词表 5 万、训练对数亿时不可行。历史解法有分层 softmax（hierarchical softmax，用哈夫曼树把分母降到 $$O(d\log|V|)$$）与负采样（把多分类改造成少量二分类），现代实现几乎都用后者——这是 Day 018 的主角；
* **学习率是真实的坑**：本节实验中，同样的代码把学习率从 0.02 提到 0.1，loss 先降后爆（第 50 轮 1.33，第 150 轮 550，第 200 轮 29540）——发散。小语料小维度尚且如此，真实训练的学习率策略（预热、线性衰减）值得专门对待；
* **向量合并**：训练完通常只用 $$\mathbf{v}$$ 表；也有工作用 $$(\mathbf{v}+\mathbf{u})/2$$ 或拼接。选择应在下游任务上验证，而不是默认；
* **评价不能只看 loss**：loss 低只说明拟合了训练对的共现分布。词向量的质量要用近邻人工抽查、相似度数据集、类比任务检验（Day 021 实验实践）。

## 10. 边界与特异性

* **本节实现的边界**：完整 softmax、固定窗口、无下采样、逐对 SGD——这是"教学完整版"，不是工业版。工业版的近似与技巧正是 Day 017–018 的内容；
* **语料规模的边界**：6 句话、24 个训练对只能演示机制。第 7 节的 0.9999 这种"过于完美"的余弦本身就是小语料的病征；
* **与计数式的深层等价**：Levy & Goldberg（2014）证明带负采样的 Skip-gram 隐式地分解一个（平移过的）PMI 矩阵——预测式与计数式在数学上殊途同归。这解释了为什么两种路线学出的向量性质相近，也说明 Day 015 的 PMI 不是绕路；
* **静态一词一向量**：训练目标是词型层面的共现分布，多义词的所有义项共享一个向量（Day 020 展开）。

## 11. 常见误区

### 误区一：Word2Vec 是"深度"神经网络

Skip-gram 本体没有隐层：查表、点积、softmax，是线性结构（log-linear）。"向量是学出来的"不等于"有很多层"。

### 误区二：Skip-gram 是语言模型

它预测窗口内**任意方向**的上下文，逐对独立、无链式结构；语言模型预测**下一个** Token 且概率连乘（Day 008）。任务不同，模型不同。

### 误区三：一个词训练时只有一个向量

中心与上下文两套（$$\mathbf{v}$$、$$\mathbf{u}$$），角色不对称。推理时才合并成一套。

### 误区四：softmax 分母可有可无

去掉分母就不是条件概率，"最大化得分"会无限增大而失去意义。负采样是**换一个可证近似的目标**，不是"省略归一化"（Day 018 细讲）。

### 误区五：loss 一路下降就万事大吉

本节 loss 收敛到 1.14，但那是拟合 24 个训练对；词向量的价值要看近邻与下游任务。loss 与向量质量没有单调关系。

### 误区六：两词余弦接近 -1 表示反义

本节实测的负余弦是 $$d=2$$ 退化几何的产物。反义词在真实词向量中通常**很近**（上下文几乎相同），分布式假设区分不了褒贬。

### 30 秒口述题

请在 30 秒内回答：

> Word2Vec（Skip-gram）的训练目标是什么？为什么它能学出语义相近的向量？

合格答案应包含：最大化真实共现的条件概率（softmax 形式）之积，等价于最小化逐对负对数似然（softmax 交叉熵）；梯度把真实共现拉近、把高概率误配推远；上下文分布相近的词被相近地拉扯，向量自然靠近——相似是涌现的，不是直接监督的。

### 基础题 1：手算单对损失

某训练对的 logits（按词表顺序）为 2、1、0、-1，真实上下文是第 1 个词。计算单对损失（自然对数）。

<details>
<summary>参考答案</summary>

$$J=-\log P(o\mid c)=-2+\ln(e^2+e^1+e^0+e^{-1})\approx-2+\ln 11.4753\approx0.4402$$。程序核对值 0.4402。若所有 logits 相同（比如全 0），损失应为 $$\ln4\approx1.386$$——均匀分布的交叉熵。

</details>

### 基础题 2：初始 loss 的理论值

向量近似全零时，初始单对 loss 是多少？本实验为什么第一轮就是 2.0794？

<details>
<summary>参考答案</summary>

logits 全部相同 ⇒ softmax 给每个词 $$1/|V|$$ ⇒ $$J=-\ln(1/|V|)=\ln|V|$$。本实验 $$\ln8=2.079442$$，实测 2.079427，偏差来自 ±0.1 的小随机初始化。训练初期 loss 应从 $$\ln|V|$$ 附近出发——这是检验实现正确性的快速手段。

</details>

### 进阶题 3：推导并解读梯度

从单对损失出发推导 $$\partial J/\partial\mathbf{u}_w$$，并用"拉向/推离"解释两项的符号。

<details>
<summary>参考答案</summary>

设 $$s_w=\mathbf{u}_w^{\top}\mathbf{v}_c$$，$$J=-s_o+\ln\sum_w e^{s_w}$$。则 $$\partial J/\partial s_w=P(w\mid c)-\mathbb{1}[w=o]$$，链式法则乘上 $$\partial s_w/\partial\mathbf{u}_w=\mathbf{v}_c$$ 得 $$\partial J/\partial\mathbf{u}_w=(P(w\mid c)-\mathbb{1}[w=o])\mathbf{v}_c$$。梯度下降时：$$w=o$$ 的一项为负，把 $$\mathbf{u}_o$$ 沿 $$\mathbf{v}_c$$ 方向拉近；其余项为正，按概率大小把各 $$\mathbf{u}_w$$ 推远。$$\mathbf{v}_c$$ 的梯度是这些推拉力按 $$\mathbf{u}_w$$ 的加权合成。

</details>

### 进阶题 4：代码审查

下面的训练片段有什么问题？

```python
for c, o in pairs:
    vc = vec_in[c]
    logits = [sum(uw[k] * vc[k] for k in range(d)) for uw in vec_out]
    probs = softmax(logits)
    loss = -log(probs[o])
    for k in range(d):
        vec_out[o][k] -= lr * vc[k]  # 只更新真实上下文的 u
    for k in range(d):
        vc[k] -= lr * vec_out[o][k]  # 只用 u_o 更新 v_c
```

<details>
<summary>参考答案</summary>

更新只作用于目标词，丢掉了"推离"项：softmax 分母仍在损失里，但非目标词的 $$\mathbf{u}_w$$ 不更新，模型会靠无限抬高目标得分来降 loss（分数失去校准，常见表现为训练发散或所有点积膨胀）；$$\mathbf{v}_c$$ 的梯度也漏掉了对全词表的加权和。正确更新必须遍历全词表（代价正是 Day 018 要解决的）。

</details>

### 面试追问 5：为什么一个词要两套向量

中心与上下文是对称任务里的两个不对称角色（预测者与被预测者）；数学上两套参数让点积结构更灵活。训练结束后合并（取 $$\mathbf{v}$$ 或 $$(\mathbf{v}+\mathbf{u})/2$$），因为下游使用不再区分角色。追问"能不能共享一套"：可以但表达力下降、训练更难收敛，属于实现取舍。

### 面试追问 6：Skip-gram 和 CBOW 怎么选

稀有词重要（领域术语、长尾）选 Skip-gram——低频词当中心词时能产出整窗训练对；追求速度、语料大而干净、关心常见词时 CBOW 更合适——窗口平均自带平滑。中文分词场景里领域词往往低频，Skip-gram 更常用。

### 项目答辩题 7：loss 正常下降，近邻却毫无语义

给出诊断路径与证据要求。

答题要点：先查数据（语料规模是否够——千万级 Token 起步；低频词是否根本没被训练到，统计词频覆盖）；再查采样（窗口是否太小/太大、高频词下采样是否开启，Day 017）；再查评价方法（近邻抽查的是低频词还是中频词、余弦是否在退化维度上）；做对照实验（换窗口/维度/语料量的网格，报告相似度数据集分数而非肉眼印象）；最后承认可能需要预训练向量或更大语料。每一步都要有数字证据。

## 一页回顾

```
路线转变：
计数式（PPMI 矩阵 |V|×|V|）→ 预测式（直接学 |V|×d 的表）
信号不变：共现统计（Day 015 分布式假设）

Skip-gram 目标：
maximize Π P(w_{t+j} | w_t)
P(o|c) = exp(u_o·v_c) / Σ_{w∈V} exp(u_w·v_c)
J(c,o) = -u_o·v_c + log Σ exp(u_w·v_c)

连接点：
单对损失 = softmax 交叉熵（Day 012）
最小化 J = 最大似然
初始 loss = ln|V|（实测 2.0794 = ln 8）

梯度（拉向/推离）：
∂J/∂u_w = (P(w|c) - [w==o]) v_c
真实上下文：拉近；其余词：按概率推远
相似是涌现结果，不是直接监督

本节实测（6 句、24 对、d=2、150 轮）：
loss 2.0794 → 1.1357
P(喜欢|自然语言)=0.30，P(机器学习|自然语言)=0.0028
  → 模型正确学到“机器学习不是它的上下文”
cos(v_自然语言, v_机器学习) = 0.9999
  → 但两向量仍收敛到一起（分布相近）
d=2 退化：其余余弦接近 ±1，绝对值失去含义

CBOW：上下文平均 → 预测中心词（对偶目标）
Skip-gram 利于稀有词；CBOW 快且平滑

瓶颈与坑：
softmax 分母 O(|V|d) → Day 018 负采样
学习率 0.1 发散（1.33→550→29540），0.02 收敛
两套向量 v/u，训练后合并
评价看近邻与下游任务，不只看 loss
```
