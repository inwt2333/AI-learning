## 1. 样本是目标函数的"数据定义"

Day 016 的损失 $$J=-\sum\log P(o\mid c)$$ 有一个隐含前提：存在一个训练对 $$(c,o)$$ 的集合。**怎样生成这个集合，本质上是在定义"共现"这个词**——窗口多大算共现？高频词算多少？这些决定比它看起来重要得多：同样的目标函数，喂不同的样本，学出完全不同的向量（Day 015 第 7 节的窗口讨论已经预告）。

完整的采样管线：

```
语料（分好词、按句切分的 Token 列表）
  → 高频词下采样（随机丢弃部分高频 Token 的出现）
  → 逐句、逐位置取中心词
  → 动态窗口（实际窗口在 [1, m] 中随机取小）
  → Skip-gram：窗口内每个词与中心词配对（2m 数量级/位置）
    CBOW：窗口内全部词打包成一个"上下文袋"（1 个样本/位置）
  → 喂给 Day 016 的损失函数
```

下面按管线顺序逐段实现。

## 2. Skip-gram 训练对：枚举、裁剪与重复

语料沿用 Day 015 的 6 句话，另加一句 5 词长句专门观察边界。先看窗口大小对总量的影响，再看长句的头尾：

```python
from collections import Counter
from math import sqrt
from random import seed, random

corpus = [
    ["我", "喜欢", "自然语言"],
    ["我", "喜欢", "机器学习"],
    ["自然语言", "很", "有趣"],
    ["机器学习", "很", "有趣"],
    ["我", "研究", "自然语言"],
    ["我", "学习", "机器学习"],
]
long_sentence = ["我", "喜欢", "自然语言", "和", "机器学习"]


def skipgram_pairs(sentence, window):
    """枚举一句的 Skip-gram 训练对：(中心词, 上下文词)，保留重复。

    输入：一句 Token 列表；window 为名义窗口 m。
    返回：二元组列表。要点有三——
      ① 中心词自己不与自己配对（i != j）；
      ② 句子头尾的窗口被"裁剪"而不是补齐（max/min 夹住边界）；
      ③ 重复对保留：同一词对出现几次就存几次，重复即训练权重。
    """
    pairs = []
    for i, center in enumerate(sentence):
        for j in range(max(0, i - window), min(len(sentence), i + window + 1)):
            if i != j:
                pairs.append((center, sentence[j]))
    return pairs


print("窗口大小对比（Day 015 的 6 句语料，每句 3 词）：")
for m in (1, 2):
    total = sum(len(skipgram_pairs(s, m)) for s in corpus)
    print(f"  window={m}: 训练对总数 = {total}")

print("\n长句的逐位置裁剪（window=2）：")
print(f"  句子 = {' '.join(long_sentence)}")
for i, center in enumerate(long_sentence):
    n_left = len(range(max(0, i - 2), i))            # 左邻实际个数
    n_right = len(range(i + 1, min(len(long_sentence), i + 3)))
    print(f"  位置 {i}（{center}）：左邻 {n_left} 个 + 右邻 {n_right} 个 = {n_left + n_right} 对")
print(f"  该句合计 = {len(skipgram_pairs(long_sentence, 2))} 对")
```

输出：

```
窗口大小对比（Day 015 的 6 句语料，每句 3 词）：
  window=1: 训练对总数 = 24
  window=2: 训练对总数 = 36

长句的逐位置裁剪（window=2）：
  句子 = 我 喜欢 自然语言 和 机器学习
  位置 0（我）：左邻 0 个 + 右邻 2 个 = 2 对
  位置 1（喜欢）：左邻 1 个 + 右邻 2 个 = 3 对
  位置 2（自然语言）：左邻 2 个 + 右邻 2 个 = 4 对
  位置 3（和）：左邻 2 个 + 右邻 1 个 = 3 对
  位置 4（机器学习）：左邻 2 个 + 右邻 0 个 = 2 对
  该句合计 = 14 对
```

三个构造细节：

* **边界裁剪**：位置 0 没有左邻、位置 4 没有右邻，窗口在句首句尾被夹小。真实实现（word2vec 的 C 代码）就是这样裁剪，**不**用 `<s>`/`</s>` 补齐——第 2 周语言模型的边界符号在这里不需要，因为窗口读的是"邻居存在与否"，不存在就没有对；
* **每句独立**：句子之间不跨界配对。第 1 句的末词与第 2 句的首词不算共现——"句"是采样的边界单位，怎样断句（Day 002）因此间接影响样本；
* **重复即权重**：

```python
full_counts = Counter()
for s in corpus:
    full_counts.update(skipgram_pairs(s, 2))
print("6 句语料中出现最多的训练对（window=2）：")
for pair, count in full_counts.most_common(3):
    print(f"  {pair} : {count}")
```

输出：

```
6 句语料中出现最多的训练对（window=2）：
  ('我', '喜欢') : 2
  ('我', '自然语言') : 2
  ('喜欢', '我') : 2
```

$$($$我， 喜欢$$)$$ 出现 2 次就被训练 2 次——把训练对看作多重集合，它与 Day 015 的共现计数矩阵**逐格相等**（Day 016 已见：window=1 时 24 对 = 矩阵总计数 24）。样本构造不是目标函数之外的杂事，它就是计数矩阵的另一种存放方式。

## 3. 动态窗口：给近处加权

固定窗口有个隐含的不公平：距离 1 的紧邻与距离 $$m$$ 的远邻，地位完全相同。但直觉上紧邻的证据更强（搭配关系几乎总在紧邻；Day 015 的 PPMI 一节里"研究-自然语言"这种紧邻搭配拿到了最高权重）。

word2vec 的解法不是加权公式，而是**采样**：处理每个位置时，先均匀抽 $$b\in[0,m-1]$$，把实际窗口缩小为 $$m-b$$。效果是近距离词对被更频繁地生成：

```python
def expected_weight(m, distance):
    """距离 k 的期望权重：能覆盖它的有效窗口个数 / m。"""
    covered = sum(1 for reduced in range(1, m + 1) if distance <= reduced)
    return covered / m


print("动态窗口的期望距离权重（m=2，b∈[0,1] 等概率）：")
for k in (1, 2):
    print(f"  距离 {k}: 期望权重 = {expected_weight(2, k):.2f}")

seed(7)
near = far = 0
for _ in range(2000):          # 重复 2000 轮观察经验频率
    for i in range(len(long_sentence)):
        b = (random() * 2) // 1  # 等概率取 0 或 1
        reduced = 2 - int(b)     # 实际窗口：2 或 1
        for j in range(max(0, i - reduced), min(len(long_sentence), i + reduced + 1)):
            if i != j:
                if abs(i - j) == 1:
                    near += 1
                else:
                    far += 1
print(f"2000 轮动态采样（长句，m=2）：距离 1 共 {near} 次，距离 2 共 {far} 次")
```

输出：

```
动态窗口的期望距离权重（m=2，b∈[0,1] 等概率）：
  距离 1: 期望权重 = 1.00
  距离 2: 期望权重 = 0.50

2000 轮动态采样（长句，m=2）：距离 1 共 16000 次，距离 2 共 6028 次
```

一般规律：距离 $$k$$ 的期望权重是 $$(m-k+1)/m$$——$$m=2$$ 时距离 1 与距离 2 的权重比是 2:1（实测 16000:6028，吻合）。等效于给近邻做了线性递减的距离加权，但用随机采样实现，代价低、且天然与逐对 SGD 兼容。

## 4. 高频词下采样：让"我"别霸场

高频词的问题是**数量失衡**：语料里"的""我"这类词的出现次数可以是内容词的几千倍，每个出现都会生成一整窗训练对。结果：绝大多数训练对都是"高频词 × 任意词"的平凡组合，稀有词的信号被淹没，梯度被高频词占据。

下采样（subsampling）按频率随机丢弃词的**出现**（occurrence）。论文版公式：词 $$w$$ 的频率占比为 $$f(w)$$、阈值为 $$t$$ 时，丢弃概率

$$
P_{\text{discard}}(w)=1-\sqrt{\frac{t}{f(w)}}
$$

（$$f(w)<t$$ 时为负，截断为 0，即低频词永不丢弃。官方 C 实现的保留公式略有不同，思想一致——引用文献里可对照。）$$t$$ 常取 $$10^{-3}\sim10^{-5}$$；本节 23 个 Token 的玩具语料必须放大到 $$t=0.1$$ 才看得到效果，这个差异本身就是"参数依赖语料规模"的实例：

```python
demo_corpus = corpus + [long_sentence]
token_total = sum(len(s) for s in demo_corpus)
freq = Counter(t for s in demo_corpus for t in s)
t = 0.1  # 真实系统 1e-3~1e-5；玩具语料放大 t 才能演示

print(f"下采样概率表（demo 语料 {token_total} 个 Token，t = {t}）：")
for word in sorted(freq, key=lambda w: -freq[w])[:4]:
    f = freq[word] / token_total
    p_discard = max(0.0, 1 - sqrt(t / f))
    print(f"  {word}: 频率 {f:.4f} → 丢弃概率 {p_discard:.4f}")

seed(11)


def subsample(sentence, t, freq, token_total):
    """逐 Token 丢弃高频词的出现。丢弃的是“出现”本身——这个词既不再
    作为中心词生成训练对，也不再出现在任何别人的窗口里。"""
    kept = []
    for token in sentence:
        f = freq[token] / token_total
        p_discard = max(0.0, 1 - sqrt(t / f))
        if random() >= p_discard:  # random() < p_discard 时丢弃
            kept.append(token)
    return kept


kept_corpus = [subsample(s, t, freq, token_total) for s in demo_corpus]
tokens_after = sum(len(s) for s in kept_corpus)
pairs_before = sum(len(skipgram_pairs(s, 2)) for s in demo_corpus)
pairs_after = sum(len(skipgram_pairs(s, 2)) for s in kept_corpus)
print(f"\n一次下采样（seed=11）：")
print(f"  Token 数：{token_total} → {tokens_after}")
print(f"  window=2 训练对：{pairs_before} → {pairs_after}")
print(f"  保留下来的句子：{[(' '.join(s) if s else '∅') for s in kept_corpus]}")
```

输出：

```
下采样概率表（demo 语料 23 个 Token，t = 0.1）：
  我: 频率 0.2174 → 丢弃概率 0.3218
  自然语言: 频率 0.1739 → 丢弃概率 0.2417
  机器学习: 频率 0.1739 → 丢弃概率 0.2417
  喜欢: 频率 0.1304 → 丢弃概率 0.1244

一次下采样（seed=11）：
  Token 数：23 → 19
  window=2 训练对：50 → 34
  保留下来的句子：['我 喜欢 自然语言', '我 喜欢 机器学习', '很 有趣', '机器学习 很 有趣', '研究 自然语言', '学习 机器学习', '我 喜欢 和 机器学习']
```

实测里第三句"自然语言 很 有趣"的"自然语言"被丢弃，剩下"很 有趣"——这次丢弃同时消灭了它作为中心词的 2 个对和它作为别人上下文的若干对。**下采样不是去停用词**：它不维护词表、按频率连续衰减、每个 epoch 重新随机（在线采样时），偶然而非永久地跳过高频词。

## 5. CBOW 样本：上下文袋预测中心词

CBOW 的样本方向相反：**每个位置一个样本**，输入是窗口内所有上下文词的"袋"（bag，无序、可重复），预测目标是中心词：

```python
print("CBOW 样本（长句，window=2）：")
for i, center in enumerate(long_sentence):
    context = [
        long_sentence[j]
        for j in range(max(0, i - 2), min(len(long_sentence), i + 3))
        if j != i  # 中心词自己绝不进上下文袋
    ]
    print(f"  (上下文袋 {context} → 中心 {center})")
print(f"  同一句：Skip-gram {len(skipgram_pairs(long_sentence, 2))} 对，"
      f"CBOW {len(long_sentence)} 个样本")
```

输出：

```
CBOW 样本（长句，window=2）：
  (上下文袋 ['喜欢', '自然语言'] → 中心 我)
  (上下文袋 ['我', '自然语言', '和'] → 中心 喜欢)
  (上下文袋 ['我', '喜欢', '和', '机器学习'] → 中心 自然语言)
  (上下文袋 ['喜欢', '自然语言', '机器学习'] → 中心 和)
  (上下文袋 ['自然语言', '和'] → 中心 机器学习)
  同一句：Skip-gram 14 对，CBOW 5 个样本
```

与 Skip-gram 的结构差异一目了然：

* **数量级**：Skip-gram 每个位置产约 $$2m$$ 个对，CBOW 每个位置只产 1 个样本——同一句 14 对 5 样本。这是"CBOW 更快、Skip-gram 对稀有词更友好"的数据层根源（Day 016 第 8 节的结论在这里落地）；
* **无序**：上下文是"袋"——模型把袋里各词的向量**平均**成一个组合向量（Day 016 的 $$\mathbf{h}$$），词序信息在输入侧被放弃；
* **边界同样裁剪**：位置 0 的袋只有 2 个词，不补齐。

## 6. 组装：从语料到训练数据

把四段拼成一条完整的 Skip-gram 采样管线（CBOW 同理，最后一步换成打包）：

```
for 每个 epoch：
  for 每句话（顺序或乱序）：
    句子 = subsample(句子)                # 高频 Token 随机消失
    for 每个位置 i：
      b ~ Uniform[0, m-1]；实际窗口 = m - b
      for j ∈ 窗口内且 j ≠ i：
        训练对 = (句子[i], 句子[j])        # 喂给 Day 016 的损失与梯度
```

三个成分各管一件事：**下采样**管"哪些词出现"、**动态窗口**管"每次看多远"、**配对**管"谁和谁组成监督信号"。它们共同定义了目标函数实际拟合的那个"共现分布"——Day 015 用固定窗口数出来的矩阵，只是这条管线在特定设置下的一个确定性特例。

## 7. 边界与特异性

* **$$t$$ 依赖语料规模**：$$t=10^{-5}$$ 对着亿级 Token 有效，搬到 23 个 Token 的语料上等于关掉下采样。换语料必须重调，并报告取值；
* **断句即边界**：句子切分方式（标点规则、长度上限）决定哪些邻居永远无法配对。中文长文无标点段落要先断句（Day 002 的规范化）；
* **分词一致性**：训练对的词就是 Tokenizer 的输出。换分词器等于换词表换样本，第 1 周的所有一致性结论适用；
* **短文本场景**：查询、标题这类"天然短句"里，边界裁剪比例极高（几乎每个位置都在句首句尾），窗口与下采样参数应专门重调，而不是沿用长文语料的默认值。

## 8. 工程权衡与失效模式

* **下采样过猛**：高频词的向量欠训练，它们在近邻检查里会显得"无处安放"；$$t$$ 越小越激进；
* **动态窗口弱化主题信号**：远距离共现被系统性降权，学出的向量偏向句法/搭配相似（Day 015 的窗口权衡再次出现，只是现在从采样侧起作用）；
* **在线采样 vs 预生成**：预生成全部训练对省了随机数开销但内存巨大（数亿对）；真实实现在线边读边采，每个 epoch 样本都不同——等价于免费的数据扰动；
* **重复对的隐性加权**：高频共现天然被反复训练，这对拟合有益，但也意味着一条语料中的模板句式会主导某些向量——领域语料要去重（Day 048 数据工程的预演）。

## 9. 常见误区

### 误区一：窗口在句首句尾要补齐

补齐（如加 PAD）是批处理对齐的手段（Day 006/010），不是采样的手段。采样只承认真实存在的邻居，边界处窗口直接裁小。

### 误区二：下采样就是去停用词

去停用词是永久的、词表级的删除；下采样是随机的、出现级的概率跳过，且频率连续影响丢弃率。两者效果有重叠，机制完全不同。

### 误区三：动态窗口是为了"数据增强"

它的唯一目的是给近距离共现更高的期望权重（$$(m-k+1)/m$$），不涉及防止过拟合。把它说成数据增强是概念错位。

### 误区四：CBOW 的上下文保序

CBOW 名字里的 B 就是 Bag：上下文向量取平均，输入侧无序。Skip-gram 同样逐对无方向偏好。

### 误区五：一个位置只生成一个训练对

Skip-gram 每个位置生成"窗口大小个"对（约 $$2m$$ 个）。这也解释了 Skip-gram 训练慢的主要来源不在模型而在样本量。

### 误区六：下采样只影响中心词

丢弃的是出现本身：该 Token 既不当中心，也从别人的窗口里消失。只在一侧生效是常见实现 bug（见练习）。

合格答案应包含：逐位置取中心词，窗口内（裁剪边界、不含自身）每个词配成对、重复保留；动态窗口均匀抽 $$b\in[0,m-1]$$ 缩小实际窗口，给近邻 $$(m-k+1)/m$$ 的期望权重；下采样按 $$1-\sqrt{t/f}$$ 随机丢弃高频词的出现，缓解平凡对淹没信号。

### 基础题 1：手数训练对

一个 6 个词的句子，window=1 能生成多少对？window=2 呢（本节 5 词长句 window=2 是 14 对，方法相同）？

<details>
<summary>参考答案</summary>

window=1：中间 4 个位置各 2 对，两端各 1 对，共 $$4\times2+2\times1=10$$ 对。window=2：位置 0、5 各 2 对；位置 1、4 各 3 对；位置 2、3 各 4 对，共 $$2+3+4+4+3+2=18$$ 对。通式：$$\sum_i\bigl(\min(m,i)+\min(m,n-1-i)\bigr)$$。

</details>

### 基础题 2：手算丢弃概率

某词频率占比 $$f=0.25$$，阈值 $$t=0.05$$。计算丢弃概率；一个频率占比 0.01 的词呢？

<details>
<summary>参考答案</summary>

$$P=1-\sqrt{0.05/0.25}=1-\sqrt{0.2}\approx0.5528$$。低频词 $$1-\sqrt{0.05/0.01}$$ 为负，截断为 0，永不丢弃——下采样只作用于 $$f>t$$ 的高频词。

</details>

### 进阶题 3：推导期望权重

证明动态窗口下距离 $$k$$ 的期望权重是 $$(m-k+1)/m$$，并列出 $$m=3$$ 时三个距离的权重。

<details>
<summary>参考答案</summary>

实际窗口 $$m-b$$ 在 $$\{1,\ldots,m\}$$ 上均匀分布；距离 $$k$$ 的对只在 $$m-b\ge k$$ 时生成，满足条件的取值有 $$m-k+1$$ 个，每个概率 $$1/m$$，故期望权重 $$(m-k+1)/m$$。$$m=3$$：距离 1、2、3 的权重分别为 $$3/3=1$$、$$2/3\approx0.667$$、$$1/3\approx0.333$$。

</details>

### 进阶题 4：代码审查

下面的采样器有什么问题？

```python
def pairs(sentence, m):
    out = []
    for i, c in enumerate(sentence):
        for j in range(i - m, i + m):   # 遍历左右各 m
            if 0 <= j < len(sentence):
                out.append((c, sentence[j]))
    return out
```

<details>
<summary>参考答案</summary>

三处：右端漏了一个邻居（`range(i-m, i+m)` 应到 `i+m+1`，off-by-one）；没有 `i != j` 判断，中心词会和自己配对；这是固定窗口（可接受但要声明），若想实现动态窗口还需要先抽 $$b$$。边界越界倒是用 `0 <= j < len` 正确处理了。

</details>

### 面试追问 5：为什么必须下采样，调大窗口不行吗

下采样解决的是"高频词制造海量平凡对"的**数量失衡**，窗口大小解决的是"看多远"的**观测尺度**，两个旋钮正交：调窗口无法减少"我"的出现次数，反而窗口越大高频词制造的平凡对越多。正确回答还应提到：丢弃的是出现（两种角色一起），并且 $$t$$ 与语料规模相关。

### 面试追问 6：窗口取 5 还是 50

小窗学句法/搭配相似，大窗学主题/领域相似（Day 015）；动态窗口默认值（word2vec 官方 demo 的 5）偏向前者。领域检索常用较大窗口加下采样，兼顾主题覆盖。回答落在"按下游任务的近邻质量选择，并做窗口消融"即可。

### 项目答辩题 7：用领域语料训练词向量，采样参数怎么定

答题要点：先固定合理默认（$$m=5$$、$$t=10^{-4}$$、Skip-gram），建立评价基线（相似度测试集 + 分层近邻抽查：功能词/内容词/领域术语分别看）；再对 $$m$$ 与 $$t$$ 做小网格，报告每个组合的近邻质量与训练时长；警惕两个失效信号——高频词语义漂移（$$t$$ 过小）与术语向量退化为噪声（语料中频次过低，需回查覆盖）；全程记录随机种子与断句规则保证可复现。

```
样本 = 目标函数的数据定义

Skip-gram 配对：
逐位置取中心词，窗口内（不含自身）逐词配对
边界裁剪（不补 PAD），句子独立（不跨句）
重复保留：训练对多重集 ≡ Day 015 共现计数矩阵
数量：每位置约 2m 个对（长句 m=2：14 对）

动态窗口：
先抽 b ∈ [0, m-1]，实际窗口 = m - b
距离 k 的期望权重 = (m-k+1)/m（近邻加倍受重视）
m=2 实测：距离 1 共 16000 次 vs 距离 2 共 6028 次

高频词下采样：
P_discard(w) = 1 - sqrt(t / f(w))，f < t 时为 0
丢弃“出现”：中心与上下文角色一起消失
解决数量失衡：高频平凡对淹没稀有信号
t 依赖语料规模（真实 1e-3~1e-5，玩具语料 0.1）
实测：23 → 19 Token，50 → 34 对

CBOW 样本：
每位置 1 个样本：上下文袋（无序、可重复）→ 中心词
袋内向量平均（Day 016 的 h）
数量对比：同句 Skip-gram 14 对 vs CBOW 5 样本
→ CBOW 快、Skip-gram 对稀有词友好

管线：下采样 → 动态窗口 → 配对/打包 → Day 016 损失
三个成分共同定义被拟合的“共现分布”

常见 bug：off-by-one 漏右邻 / 中心词进上下文 /
跨句配对 / 下采样只作用一侧角色
```
