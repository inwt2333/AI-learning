# Day 018：负采样如何降低计算量

## 1. 瓶颈的算术

Full softmax 的每个训练对 $$(c,o)$$ 都要做两件昂贵的事：给**全词表**的每个词算点积 $$\mathbf{u}_w^{\top}\mathbf{v}_c$$（分母），再更新**全词表**的每个 $$\mathbf{u}_w$$（推离项牵动所有词）。算一笔账：

```python
V_real, k_real, pairs_per_epoch = 50000, 5, 100_000_000
full_ops = V_real * pairs_per_epoch            # 每对 |V| 次点积
sgns_ops = (k_real + 1) * pairs_per_epoch      # 每对只碰 k+1 个词
print(f"词表 {V_real}，训练对 1 亿/轮：")
print(f"  full softmax：{full_ops:.2e} 次点积/轮")
print(f"  负采样(k=5)：{sgns_ops:.2e} 次点积/轮")
print(f"  缩减倍数 ≈ {full_ops / sgns_ops:.0f}×")
```

输出：

```
词表 50000，训练对 1 亿/轮：
  full softmax：5.00e+12 次点积/轮
  负采样(k=5)：6.00e+08 次点积/轮
  缩减倍数 ≈ 8333×
```

一轮 5 万亿次点积不可行，这就是 Day 016 留下的坑。注意瓶颈的来源：不是模型大（$$\mathbf{v}$$、$$\mathbf{u}$$ 表本身只有 $$|V|\times d$$ 个参数），而是**归一化要求每个样本都面对整个词表**。

## 2. 想法：把多分类换成 k+1 个二分类

负采样的思路转换：不再问"给定 $$c$$，全词表中每个词是上下文的概率是多少"，而是把任务改成一组**判断题**：

```
训练对 (c = 自然语言, o = 喜欢)
  正例：(自然语言, 喜欢)      → 标签 1（真实共现）
  负例：(自然语言, w̄₁)       → 标签 0（w̄₁ 按分布抽出，如“有趣”）
  负例：(自然语言, w̄₂)       → 标签 0（如“学习”）
  每个判断只算一个点积、过一个 sigmoid —— 共 k+1 次，与 |V| 无关
```

每个判断是标准二分类：$$\sigma(x)=1/(1+e^{-x})$$ 把点积 $$\mathbf{u}^{\top}\mathbf{v}$$ 压到 $$(0,1)$$ 当"是上下文"的打分。负例不是人工挑的"易混词"，是从一个指定分布里随机抽的**噪声词**——任务因此变成"区分真实共现与随机配对"。

## 3. 目标函数与梯度

对训练对 $$(c,o)$$ 与 $$k$$ 个负例 $$\bar w_1,\ldots,\bar w_k$$，损失为：

$$
J_{(c,o)}=-\log\sigma(\mathbf{u}_o^{\top}\mathbf{v}_c)
-\sum_{i=1}^{k}\log\sigma(-\mathbf{u}_{\bar w_i}^{\top}\mathbf{v}_c)
$$

第一项要求正例的分数尽量大；第二项要求负例的分数尽量小。对任一参与判断的词 $$w$$（标签 $$y\in\{1,0\}$$，得分 $$s=\mathbf{u}_w^{\top}\mathbf{v}_c$$）：

$$
\frac{\partial}{\partial\mathbf{u}_w}\bigl[-\log\sigma(\pm s)\bigr]
=\bigl(\sigma(s)-y\bigr)\mathbf{v}_c
$$

系数又是"预测减目标"：正例 $$\sigma(s)-1<0$$ 把 $$\mathbf{u}_o$$ 拉向 $$\mathbf{v}_c$$；负例 $$\sigma(s)>0$$ 把 $$\mathbf{u}_{\bar w}$$ 推远——Day 016 的拉推图景原样保留，只是**每对只动** $$k+1$$ **个向量，而不是全词表**。

**初始 loss 的理论值**：小随机初始化时所有点积近零，$$-\log\sigma(0)=\ln2$$，于是每对初始损失是：

$$
(k+1)\ln2
$$

$$k=2$$ 时为 $$3\times0.6931=2.0794$$。这继承自 Day 016 的 $$\ln|V|$$ 自检法：训练第一轮的 loss 应从这个值附近出发，差得远就是实现有 bug。

## 4. 负例从哪来：unigram 的 0.75 次幂

负例分布 $$P_n$$ 的选择：$$P_n(w)\propto\operatorname{count}(w)^{0.75}$$，即先按词频取 0.75 次幂再归一化。效果是**把分布压平一点点**：高频词仍更常被抽中（保持"常见词更需要学会推开"），但比例被削减；低频词获得相对更多的出场。

```python
from collections import Counter

corpus = [
    ["我", "喜欢", "自然语言"],
    ["我", "喜欢", "机器学习"],
    ["自然语言", "很", "有趣"],
    ["机器学习", "很", "有趣"],
    ["我", "研究", "自然语言"],
    ["我", "学习", "机器学习"],
]

counts = Counter(t for s in corpus for t in s)
total = sum(counts.values())
p_unigram = {w: c / total for w, c in counts.items()}
p_smooth = {w: c ** 0.75 for w, c in counts.items()}
z = sum(p_smooth.values())
p_smooth = {w: v / z for w, v in p_smooth.items()}

print("负例分布对比（18 Token 语料）：")
print(f"{'词':<6}{'unigram':>10}{'unigram^0.75':>14}{'变化':>10}")
for w in sorted(p_unigram, key=lambda x: -p_unigram[x]):
    delta = p_smooth[w] / p_unigram[w]
    print(f"{w:<6}{p_unigram[w]:>10.4f}{p_smooth[w]:>14.4f}{delta:>9.2f}x")
```

输出：

```
负例分布对比（18 Token 语料）：
词        unigram  unigram^0.75        变化
我         0.2222        0.1960     0.88x
自然语言      0.1667        0.1579     0.95x
机器学习      0.1667        0.1579     0.95x
喜欢        0.1111        0.1165     1.05x
很         0.1111        0.1165     1.05x
有趣        0.1111        0.1165     1.05x
研究        0.0556        0.0693     1.25x
学习        0.0556        0.0693     1.25x
```

高频的"我"份额缩到 0.88 倍，最低频的"研究""学习"升到 1.25 倍。0.75 是 Mikolov 团队的经验值（论文原话是"在包括任务性能的多种取舍下表现良好"），不是理论最优——面试里如实说"经验选择、压平分布"即可。官方 C 实现用一张一亿格的**unigram table**（词编号按 $$\text{count}^{0.75}$$ 比例重复填充）配均匀随机数完成 O(1) 抽样，思想与本节轮盘赌一致。

## 5. Python 实现：SGNS 训练实测

把第 3、4 节拼成完整训练。语料、训练对（window=1，24 对）与 Day 016 完全一致，只有损失与更新换成负采样：

```python
from math import exp, log, sqrt
from random import seed, random, uniform

vocab = sorted(counts)
word_to_id = {w: i for i, w in enumerate(vocab)}
V, d = len(vocab), 2
id_p_smooth = [p_smooth[w] for w in vocab]

pairs = []
for sentence in corpus:
    for i, center in enumerate(sentence):
        for j in range(max(0, i - 1), min(len(sentence), i + 2)):
            if i != j:
                pairs.append((word_to_id[center], word_to_id[sentence[j]]))

def sigmoid(x):
    return 1 / (1 + exp(-x))

def sample_negative(rng, exclude, weights):
    """按 weights 抽一个负例，撞上正例就重抽（拒绝采样）。"""
    while True:
        r = rng()  # 轮盘赌：随机数落在哪个词的概率区间就选谁
        acc = 0.0
        for wid, p in enumerate(weights):
            acc += p
            if r < acc:
                if wid != exclude:
                    return wid
                break

def train(k=2, lr=0.05, epochs=200, rng_seed=42, init_scale=0.1):
    """SGNS 训练：每对组装 1 个正例 + k 个负例，做 k+1 次二分类更新。"""
    seed(rng_seed)
    vec_in = [[uniform(-init_scale, init_scale) for _ in range(d)] for _ in range(V)]
    vec_out = [[uniform(-init_scale, init_scale) for _ in range(d)] for _ in range(V)]
    history = []
    for epoch in range(epochs):
        total_loss = 0.0
        for c, o in pairs:
            # 组装 k+1 个二分类样本：1 个正例（标签 1）+ k 个负例（标签 0）。
            involved = [(o, 1)]
            for _ in range(k):
                involved.append((sample_negative(random, o, id_p_smooth), 0))
            grads_v = [0.0] * d  # v_c 的梯度先累积，循环结束再更新一次
            for w, y in involved:
                vc, uw = vec_in[c], vec_out[w]
                s = sum(uw[t] * vc[t] for t in range(d))
                total_loss -= log(sigmoid(s)) if y else log(sigmoid(-s))
                g = sigmoid(s) - y  # 梯度系数：正例拉、负例推
                for t in range(d):
                    uw[t] -= lr * g * vc[t]
                    grads_v[t] += g * uw[t]
            for t in range(d):
                vec_in[c][t] -= lr * grads_v[t]
        history.append(total_loss / len(pairs))
    return vec_in, vec_out, history

vec_in, vec_out, history = train()
print("SGNS 训练（k=2, lr=0.05, 200 轮）：")
for e in range(0, 200, 40):
    print(f"  epoch {e:>3}: 平均 loss = {history[e]:.6f}")
print(f"  epoch 199: 平均 loss = {history[-1]:.6f}")
print(f"  （理论初始值 (k+1)·ln2 = {3 * log(2):.4f}）")
```

输出：

```
SGNS 训练（k=2, lr=0.05, 200 轮）：
  epoch   0: 平均 loss = 2.079957
  epoch  40: 平均 loss = 1.730882
  epoch  80: 平均 loss = 1.331216
  epoch 120: 平均 loss = 1.306045
  epoch 160: 平均 loss = 1.523272
  epoch 199: 平均 loss = 1.125822
  （理论初始值 (k+1)·ln2 = 2.0794）
```

初始值 2.079957 与理论 2.0794 吻合（偏差来自小随机初始化）。曲线**不是单调下降**（160 轮处还回升到 1.52）——负例每个 epoch 重新随机抽取，loss 随"这轮抽到了哪些负例"波动，看趋势不看单调性，这是 SGNS 与 full softmax 在训练观感上的一个实际差异。

训练后的检查：

```python
def score(context, center):
    """σ(u·v)：训练诊断分数，未归一化，不是条件概率。"""
    vc = vec_in[word_to_id[center]]
    uw = vec_out[word_to_id[context]]
    return sigmoid(sum(a * b for a, b in zip(uw, vc)))

print("σ(u·v) 分数（>0.5 偏向“是上下文”）:")
for ctx, ctr, tag in (("喜欢", "自然语言", "正例"), ("很", "自然语言", "正例"),
                      ("机器学习", "自然语言", "非上下文"), ("有趣", "自然语言", "非上下文")):
    print(f"  σ({ctx} | {ctr}) = {score(ctx, ctr):.4f}   [{tag}]")

def cos(a, b):
    na = sqrt(sum(x * x for x in a))
    nb = sqrt(sum(x * x for x in b))
    return sum(x * y for x, y in zip(a, b)) / (na * nb)

target = word_to_id["自然语言"]
print("\nv 表近邻（自然语言）：")
ranked = sorted(
    ((cos(vec_in[target], vec_in[i]), w)
     for i, w in enumerate(vocab) if w != "自然语言"),
    reverse=True,
)
for s, w in ranked:
    print(f"  cos(自然语言, {w}) = {s:.4f}")

print(f"\n每轮向量更新次数：full softmax = {len(pairs) * (V + 1)}，"
      f"SGNS(k=2) = {len(pairs) * 3}")
```

输出：

```
σ(u·v) 分数（>0.5 偏向“是上下文”）:
  σ(喜欢 | 自然语言) = 0.6948   [正例]
  σ(很 | 自然语言) = 0.6712   [正例]
  σ(机器学习 | 自然语言) = 0.0046   [非上下文]
  σ(有趣 | 自然语言) = 0.0082   [非上下文]

v 表近邻（自然语言）：
  cos(自然语言, 机器学习) = 0.9999
  cos(自然语言, 我) = 0.9871
  cos(自然语言, 有趣) = 0.9803
  cos(自然语言, 喜欢) = -0.0489
  cos(自然语言, 很) = -0.0781
  cos(自然语言, 研究) = -0.0854
  cos(自然语言, 学习) = -0.1141

每轮向量更新次数：full softmax = 216，SGNS(k=2) = 72
```

三组结果对照着读：

* **二分类任务学会了**：真实上下文（喜欢、很）的 $$\sigma$$ 约 0.67–0.69，非上下文（机器学习、有趣）被压到 0.005–0.008——注意"机器学习"频繁被抽为负例，模型学到的是"它不是自然语言的上下文"，与 Day 016 的 $$P=0.0028$$ 结论一致；
* **语义相似照样涌现**：$$\cos(\mathbf{v}_{\text{自然语言}},\mathbf{v}_{\text{机器学习}})=0.9999$$——换了目标函数，"共享上下文分布 ⇒ 向量相近"的现象不变（$$d=2$$ 的退化几何同 Day 016 的讨论，余弦只看排序）；
* **代价差异落到了数字上**：玩具词表里每轮向量更新 216 对 72 次（3 倍）；真实词表下就是第 1 节的 8333 倍。

## 6. 它在优化什么：不是 softmax 的近似

必须说清的一件事：**SGNS 的目标函数不是 full softmax 目标的近似，而是另一个目标**。三点差异：

1. **没有归一化**：$$\sigma(u\cdot v)$$ 只是一个二分类打分，$$\sum_w\sigma(\mathbf{u}_w^{\top}\mathbf{v}_c)$$ 不等于 1。训练完的模型**给不出条件概率** $$P(o\mid c)$$——Day 012 的规则照旧适用：没有归一化的分数不能进困惑度、不能当概率解读（Day 010 误区七的呼应）；
2. **血统是 NCE**：负采样源自噪声对比估计（Noise-Contrastive Estimation，Gutmann & Hyvärinen 2010）——用"区分数据与噪声"来估计未归一化统计模型。word2vec 的版本做了简化（每步只抽 $$k$$ 个噪声、不做完整 NCE 修正），因此 Goldberg & Levy（2014）专门推导了它的确切目标；
3. **隐式分解平移 PMI 矩阵**：Levy & Goldberg（2014）证明 SGNS 等价于加权分解一个元素为 $$\operatorname{PMI}(w,c)-\log k$$ 的矩阵。这一条把三天连成闭环：Day 015 的 PMI 计数、Day 016 的 softmax 似然、今天的负采样，是同一统计信号的三种计算方案。$$-\log k$$ 平移也解释了 $$k$$ 的另一个作用：它移动了"多共现才算正"的门槛。

## 7. 参数与工程实践

* $$k$$ **的取值**：原论文建议小语料 5–20、大语料 2–5。直觉：$$k$$ 越大，每次更新的"推离"覆盖越广、信号更稳，但正例的相对权重被稀释、更新成本线性增加；大规模下每个正例见很多次，小 $$k$$ 足够；
* **负例撞正例**：抽到的负例等于真实上下文时（小词表常见），标准做法是拒绝重抽（本节 `sample_negative` 的实现）；有的实现容忍少量冲突，需要在报告里声明；
* **与 Day 017 的下采样正交**：下采样改"哪些正例出现"，负采样改"配哪些反例"，两者独立调节；
* **在线抽负例**：每个 epoch 负例都重新随机——和 Day 017 动态窗口一样，自带数据扰动；
* **现代回响**：SGNS 的"正例拉近、负例推远"正是对比学习（contrastive learning）的标准结构；InfoNCE 损失（Day 079）可以看作"用 softmax 归一化的负采样"——分母里的负例集合替代全词表。今天理解的结构直接迁移到文本 Embedding 训练。

## 8. 边界与特异性

* **负例分布绑定训练语料**：$$P_n$$ 来自训练语料的词频。领域语料与通用语料的词频差异很大，用通用向量到领域文本，负例分布与实际分布错位是效果折扣的来源之一；
* $$k$$ **不是越大越好**：过大的 $$k$$ 稀释正例梯度（每对里正例只占 $$1/(k{+}1)$$），小语料上还会把低频词的 $$\mathbf{u}$$ 推得过度；
* **loss 波动是常态**：负例随机重抽使 epoch 间 loss 可比性有限，调试时应看滑动平均与最终近邻质量；
* **本节实现的边界**：拒绝采样抽负例在玩具词表上够用；真实词表用 unigram table 或别名法（alias method）做 O(1) 抽样，逐词轮盘赌太慢。

## 9. 常见误区

### 误区一：负采样是 softmax 的近似

它是另一个目标函数（NCE 简化版），收敛结果不等于 full softmax 的收敛结果。说"近似"时，近似的对象是"学好词向量"这个任务，不是那个公式。

### 误区二：负例是"容易混淆的词"

负例来自按频率的随机分布，不是难例挖掘（hard negative mining）。"区分真实共现与随机配对"已经足够学出好向量；难例挖掘是后续工作（对比学习里才系统化）。

### 误区三：σ 分数可以当概率比较

$$\sigma(u\cdot v)$$ 未归一化：$$\sigma(\text{喜欢})=0.69$$ 与 $$\sigma(\text{很})=0.67$$ 之差不构成概率意义的比较，更不能说"模型认为 69% 是上下文"（Day 012 的支撑与归一化要求）。

### 误区四：k 越大效果越好

$$k$$ 平衡了负例覆盖与正例稀释（并平移 PMI 门槛 $$\log k$$）。大语料反而用小 $$k$$，因为有足够的正例重复次数。

### 误区五：loss 必须单调下降才算训练正常

负例随机重抽导致 loss 波动（本节 160 轮处回升到 1.52 又降到 1.13）。判断训练健康看初始值自检、趋势与近邻质量。

### 误区六：负采样让模型变小

$$|V|\times d$$ 的参数表一点没小；省的是**每步计算量**（分母与全表更新）。参数量瓶颈要靠别的手段（量化、裁剪词表、Day 060 的 LoRA 思想）。

合格答案应包含：full softmax 分母与全表更新是 $$O(|V|)$$ 瓶颈；负采样把多分类改成 1 个正例 + $$k$$ 个负例的 logistic 二分类，每对只碰 $$k+1$$ 个向量（真实词表约 8000 倍缩减）；代价是目标不再是归一化的条件概率，且负例带来训练方差。

### 基础题 1：手算初始 loss

$$k=5$$ 时，SGNS 每个训练对的初始 loss（小随机初始化）是多少？

<details>

<summary>参考答案</summary>

每个判断贡献 $$-\log\sigma(0)=\ln2\approx0.6931$$，共 $$k+1=6$$ 个，初始 loss $$=6\ln2\approx4.1589$$。同理 $$k=2$$ 时为 2.0794（本节实测 2.079957）。这是 SGNS 版的"Day 016 自检"。

</details>

### 基础题 2：判断分布变化

把负例分布从 $$\text{unigram}^{0.75}$$ 换成纯 unigram，再换成 $$\text{unigram}^{0.5}$$，各词被抽中的相对概率怎样变化？哪种最"平"？

<details>

<summary>参考答案</summary>

指数越小分布越平：unigram（指数 1）下高频词按频率占比被抽中；0.75 已把"我"压到 0.88 倍、低频词抬到 1.25 倍；0.5 压得更狠，趋向均匀。极限是指数 0，即均匀分布。太平时负例失去"常见词要多推"的针对性，太陡则低频词几乎从不被推——0.75 是经验折中。

</details>

### 进阶题 3：推导梯度系数

从 $$-\log\sigma(s)$$（正例）与 $$-\log\sigma(-s)$$（负例）出发，证明两者的梯度系数都统一为 $$\sigma(s)-y$$。

<details>

<summary>参考答案</summary>

$$\sigma'(s)=\sigma(s)(1-\sigma(s))$$。正例：$$\frac{d}{ds}[-\log\sigma(s)]=-\frac{\sigma'(s)}{\sigma(s)}=-(1-\sigma(s))=\sigma(s)-1$$。负例：$$\frac{d}{ds}[-\log\sigma(-s)]=\frac{\sigma'(-s)}{\sigma(-s)}=\sigma(-s)\cdot\frac{1-\sigma(-s)}{\sigma(-s)(1-\sigma(-s))}\cdot(1-\sigma(-s))$$，化简得 $$\sigma(-s)=1-\sigma(s)$$，即 $$\sigma(s)-0$$。统一为 $$\sigma(s)-y$$。

</details>

### 进阶题 4：代码审查

下面的 SGNS 更新片段有什么问题？

```python
for c, o in pairs:
    negs = [random.choice(vocab_ids) for _ in range(k)]  # 抽 k 个负例
    for w in [o] + negs:
        s = dot(vec_out[w], vec_in[c])
        g = sigmoid(s) - 1               # 梯度系数
        update(vec_out[w], g * vec_in[c])
```

<details>

<summary>参考答案</summary>

* 梯度系数写死为 $$\sigma(s)-1$$：负例应减标签 0，即系数 $$\sigma(s)$$，现在负例也在被"拉近"，方向整个反了；
* 负例用均匀 `random.choice`，没有按 $$\text{unigram}^{0.75}$$ 分布（也不排除撞上正例 $$o$$）；
* $$\mathbf{v}_c$$ 没有更新（只更新了 $$\mathbf{u}$$）。

</details>

### 面试追问 5：为什么用 0.75 次幂，不是 1 或 0.5

指数 1（纯频率）让高频词垄断负例名额，低频词几乎从不被推开、向量得不到校准；指数太小则走向均匀，失去"常见词更需要推"的先验。0.75 是论文报告的经验值：压平但不抹平。回答时补一句"论文没有理论推导，属于实证选择"更严谨。

### 面试追问 6：SGNS 与 full softmax 学出的向量有何异同

同：都由共现统计驱动，近邻质量总体接近（Levy & Goldberg：SGNS 隐式分解 PMI-log k 矩阵，与计数路线殊途同归）。异：目标不同——softmax 拟合归一化条件分布，SGNS 拟合"共现 vs 噪声"的判别面；softmax 模型可以直接算困惑度，SGNS 的分数未归一化不能；$$k$$ 会平移隐式 PMI 的门槛。

### 项目答辩题 7：SGNS 训练的调参与诊断

答题要点：先核对初始 loss $$(k+1)\ln2$$ 确认实现无误；观察 loss 滑动平均（负例随机导致波动，不追求单调）；用 $$\sigma$$ 分数抽查正例/非上下文词的区分度；对 $$k\in\{2,5,10\}$$ 做小网格，报告近邻质量（分层抽查）与训练时长；对照 Day 017 的下采样开关确认两者独立起作用；最终以相似度测试集分数而非训练 loss 定参数，记录种子可复现。
