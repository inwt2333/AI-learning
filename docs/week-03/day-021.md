## 1. 实验设计

三个问题：

1. **涌现**：语料只有"词出现在什么句子里"的信息，没有任何"哪些词同类"的标签——训练后同类词会不会自动靠近？
2. **多义**：Day 020 用计数向量论证了静态表示混合多义；换成**训练出来的** SGNS 向量，双义词会落在哪里？
3. **过头**：多训练一定更好吗？loss 和向量质量是一回事吗？

数据流全景：

```
模板语料（两类 × 各 4 模板 × 3 重复，含双义词苹果）
  → Day 017 训练对枚举（window=2）
  → Day 018 SGNS 训练（k=2，unigram^0.75 负例）
  → v 表（输入向量）
  → 评价：top-2 近邻纯度 / 类内与跨类平均余弦 / 苹果的近邻分布
  → 消融：维度 d × 3 种子
```

## 2. 语料构造：可控实验床

真实语料无法回答"类结构是否正确涌现"——因为没有真值。解决办法是**模板造句**：水果类和公司类各有一套专属上下文词，语料里唯一的"跨类信息"是双义词"苹果"同时出现在两族模板中：

```python
from collections import Counter
from itertools import combinations
from math import exp, log, sqrt
from random import seed, random, uniform

FRUITS = ["苹果", "香蕉", "橙子", "葡萄"]
COMPANIES = ["小米", "华为", "苹果", "谷歌"]  # 苹果双义：同时出现在两个模板族

FRUIT_TEMPLATES = [
    ["我", "吃", "{X}"],
    ["{X}", "很", "甜"],
    ["{X}", "味道", "新鲜"],
    ["买", "一些", "{X}"],
]
COMPANY_TEMPLATES = [
    ["{X}", "发布", "手机"],
    ["{X}", "推出", "芯片"],
    ["{X}", "市值", "上涨"],
    ["关注", "{X}", "动态"],
]

REPEATS = 3  # 每个词×每个模板重复 3 次

def build_corpus():
    """按模板批量造句：两个模板族各有一套专属上下文词，苹果两族都进。"""
    corpus = []
    for _ in range(REPEATS):
        for x in FRUITS:
            for tpl in FRUIT_TEMPLATES:
                corpus.append([x if t == "{X}" else t for t in tpl])
        for x in COMPANIES:
            for tpl in COMPANY_TEMPLATES:
                corpus.append([x if t == "{X}" else t for t in tpl])
    return corpus

corpus = build_corpus()
tokens = [t for s in corpus for t in s]
print(f"句子数 = {len(corpus)}，Token 数 = {len(tokens)}，词表大小 = {len(set(tokens))}")

LABELS = {w: "水果" for w in FRUITS}
LABELS.update({w: "公司" for w in COMPANIES})
POLY = "苹果"
SINGLE_WORDS = [w for w in FRUITS + COMPANIES if w != POLY]  # 6 个单义词，评价用
```

输出：

```
句子数 = 96，Token 数 = 288，词表大小 = 23
```

96 句、288 个 Token、23 个词——小到纯 Python 秒级训练，大到足以让结构信号淹没噪声。**类标签只用于评价，训练过程完全看不到它们**（无监督）。

## 3. 训练器与基线配置

训练器是 Day 018 的 SGNS（Day 019 的 $$\mathbf{p}-\mathbf{y}$$ 梯度），只把窗口换成 2：

```python
def build_pairs(corpus, window=2):
    """枚举 Skip-gram 训练对（Day 017 的方法，窗口取 2）。"""
    pairs = []
    for sentence in corpus:
        for i, center in enumerate(sentence):
            for j in range(max(0, i - window), min(len(sentence), i + window + 1)):
                if i != j:
                    pairs.append((center, sentence[j]))
    return pairs

def train_sgns(corpus, d=10, k=2, lr=0.05, epochs=20, rng_seed=42):
    """在给定语料上训练 SGNS 词向量，返回词表、索引和 v 表。

    与 Day 018 的训练器相同：负例按 unigram^0.75 抽取、撞正例重抽、
    逐对做 k+1 个二分类更新。这里只返回最终的 v（输入表）。
    """
    counts = Counter(t for s in corpus for t in s)
    power = {w: c ** 0.75 for w, c in counts.items()}
    z = sum(power.values())
    vocab = sorted(counts)
    weights = [power[w] / z for w in vocab]        # 负例采样分布
    word_to_id = {w: i for i, w in enumerate(vocab)}
    V = len(vocab)
    pairs = [(word_to_id[c], word_to_id[o]) for c, o in build_pairs(corpus)]

    def sample_negative(rng, exclude):
        while True:  # 轮盘赌抽样；撞上正例就重抽
            r = rng()
            acc = 0.0
            for wid, p in enumerate(weights):
                acc += p
                if r < acc:
                    if wid != exclude:
                        return wid
                    break

    def sigmoid(x):
        return 1 / (1 + exp(-x))

    seed(rng_seed)
    vec_in = [[uniform(-0.1, 0.1) for _ in range(d)] for _ in range(V)]
    vec_out = [[uniform(-0.1, 0.1) for _ in range(d)] for _ in range(V)]
    avg_loss = None
    for epoch in range(epochs):
        total_loss = 0.0
        for c, o in pairs:
            involved = [(o, 1)] + [(sample_negative(random, o), 0) for _ in range(k)]
            grads_v = [0.0] * d
            for w, y in involved:
                vc, uw = vec_in[c], vec_out[w]
                s = sum(uw[t] * vc[t] for t in range(d))
                total_loss -= log(sigmoid(s)) if y else log(sigmoid(-s))
                g = sigmoid(s) - y  # Day 019 的 p - y
                for t in range(d):
                    uw[t] -= lr * g * vc[t]
                    grads_v[t] += g * uw[t]
            for t in range(d):
                vec_in[c][t] -= lr * grads_v[t]
        avg_loss = total_loss / len(pairs)
    return vocab, word_to_id, vec_in, avg_loss

def cos(a, b):
    na = sqrt(sum(x * x for x in a))
    nb = sqrt(sum(x * x for x in b))
    return sum(x * y for x, y in zip(a, b)) / (na * nb)

def neighbors(word, vocab, word_to_id, vec_in, topn=3, restrict=None):
    """按余弦列近邻；restrict 限定只在给定词集合内排。"""
    i = word_to_id[word]
    scored = [
        (cos(vec_in[i], vec_in[j]), w)
        for j, w in enumerate(vocab)
        if w != word and (restrict is None or w in restrict)
    ]
    return sorted(scored, reverse=True)[:topn]
```

基线配置：$$d=10$$、$$k=2$$、$$\eta=0.05$$、20 轮、种子 42。学习率沿用 Day 018 的收敛区间（0.1 会发散——Day 016/018 的教训不变）。

## 4. 评价设计：两个指标

**指标一：top-2 近邻纯度。** 每个单义词有且只有 2 个同类词，所以取 top-2：命中的同类数除以 2，再对 6 个词取平均。取 top-3 会把指标**饱和**在 2/3（第三个必然是异类）——指标口径必须与"可能的最大命中数"对齐，这是本实验踩过并修正的设计坑。

**指标二：类间隔。** 6 个单义词两两组合成 15 对（3 对同类、12 对跨类），分别算平均余弦，间隔 = 类内均值 − 跨类均值。纯度是 0/1 计数，间隔给出连续的分离程度。

## 5. 基线结果：类结构涌现

```python
vocab, word_to_id, vec_in, avg_loss = train_sgns(corpus, d=10, epochs=20)
print(f"基线（d=10, k=2, lr=0.05, 20 轮）：最终平均 loss = {avg_loss:.4f}")

def evaluate(vocab, word_to_id, vec_in):
    """两个指标：top-2 近邻纯度（6 个单义词内）与类内/跨类平均余弦。"""
    correct = 0
    for w in SINGLE_WORDS:
        top2 = neighbors(w, vocab, word_to_id, vec_in, topn=2, restrict=set(SINGLE_WORDS))
        correct += sum(1 for _, n in top2 if LABELS[n] == LABELS[w])
    purity = correct / (len(SINGLE_WORDS) * 2)
    within, cross = [], []
    for a, b in combinations(SINGLE_WORDS, 2):
        c = cos(vec_in[word_to_id[a]], vec_in[word_to_id[b]])
        (within if LABELS[a] == LABELS[b] else cross).append(c)
    return purity, sum(within) / len(within), sum(cross) / len(cross)

purity, within_avg, cross_avg = evaluate(vocab, word_to_id, vec_in)
print(f"top-2 近邻纯度 = {purity:.4f}，类内均 cos = {within_avg:.4f}，跨类均 cos = {cross_avg:.4f}")

print("\n单义词 top-2 近邻：")
for w in SINGLE_WORDS:
    top2 = neighbors(w, vocab, word_to_id, vec_in, topn=2, restrict=set(SINGLE_WORDS))
    print(f"  {w}({LABELS[w]}) → {[(n, round(s, 3)) for s, n in top2]}")

print("\n双义词苹果 top-5（全部词）：")
for s, n in neighbors("苹果", vocab, word_to_id, vec_in, topn=5):
    print(f"  苹果 → {n} ({LABELS.get(n, '功能词')})  cos = {s:.4f}")
```

输出：

```
基线（d=10, k=2, lr=0.05, 20 轮）：最终平均 loss = 1.0456
top-2 近邻纯度 = 1.0000，类内均 cos = 0.9919，跨类均 cos = 0.3022

单义词 top-2 近邻：
  香蕉(水果) → [('橙子', 0.996), ('葡萄', 0.991)]
  橙子(水果) → [('香蕉', 0.996), ('葡萄', 0.99)]
  葡萄(水果) → [('香蕉', 0.991), ('橙子', 0.99)]
  小米(公司) → [('谷歌', 0.992), ('华为', 0.99)]
  华为(公司) → [('谷歌', 0.993), ('小米', 0.99)]
  谷歌(公司) → [('华为', 0.993), ('小米', 0.992)]

双义词苹果 top-5（全部词）：
  苹果 → 华为 (公司)  cos = 0.8045
  苹果 → 谷歌 (公司)  cos = 0.8040
  苹果 → 小米 (公司)  cos = 0.7914
  苹果 → 香蕉 (水果)  cos = 0.7016
  苹果 → 橙子 (水果)  cos = 0.6963
```

两个核心结论，各有细节：

**类结构涌现了。** 训练只见过"谁和谁同窗"，从未见过"谁和谁同类"；结果 6 个单义词的 top-2 全部命中同类（纯度 1.0），类内余弦 0.99 级、跨类只有 0.30。语义类不是被注入的，是从共现统计里长出来的——第 3 周的全部理论（Day 015 的假设、Day 016 的拉推、Day 018 的负采样）在这一刻闭环。

**双义词落在两簇之间。** 苹果的 top-5 混着公司三杰与水果两词，且它到两类的余弦（0.70–0.80）都明显低于同类内部（0.99）——**它不在任何一个簇里，悬在两簇之间**。Day 020 用计数向量得出的结论，在训练出来的向量上原样复现。一个诚实的细节：苹果的近邻略偏公司侧（三个公司词排在前面），并非两类频率不均（各 12 句），而是两族模板中 $$\{X\}$$ 的位置分布不完全对称（公司族里 $$\{X\}$$ 更多处于句首、紧邻上下文词的位置）——信号强度有细微差别，模板造语料做不到完美对称，如实记录。

## 6. 失效案例一：训练过头，loss 反弹

把 20 轮延长到 60 轮：

```python
v2, i2, vi2, loss60 = train_sgns(corpus, d=10, epochs=60)
p60, w60, c60 = evaluate(v2, i2, vi2)
print(f"60 轮对照：loss = {loss60:.4f}，纯度 = {p60:.4f}，"
      f"类内 = {w60:.4f}，跨类 = {c60:.4f}")
```

输出：

```
60 轮对照：loss = 6.2445，纯度 = 1.0000，类内 = 0.9772，跨类 = -0.2366
```

loss 从 1.05 **涨回 6.24**（远高于初始的 2.08），而纯度纹丝不动。逐段看轨迹（同一配置，每 10 轮记录一次）：

```
epoch  0: 2.0772   ← 初始值 ≈ (k+1)·ln2，实现自检通过
epoch 10: 1.2114   ← 正常下降
epoch 20: 1.0239   ← 几何结构此时已经正确（本节基线取在这里）
epoch 30: 1.0502   ← 开始回升
epoch 50: 2.0220
epoch 59: 6.2445   ← 反弹到初始值的三倍
```

原因出在本语料的**交叉设计**与负采样的交互：模板让每个水果词都与"吃/甜/味道/买"共现，于是当训练对是（吃， 苹果）时，按频率抽到的负例"香蕉"其实是**别处的真实正例**（香蕉也真的和吃共现）。模型被同时要求推远它（当负例）和拉近它（当正例），分数层面的冲突随训练加深，loss 越推越高；而**几何层面**（谁靠近谁）由正例主导，早已正确且不再改变。

三条教训：

* **loss 与向量质量会脱钩**（Day 016/018 的"误区五"在这里有了实测证据）；
* **早停是真实的需要**，不是装饰——本实验在 20 轮附近就该停；
* 真实语料里共现远比模板稀疏，"负例其实是正例"的冲突温和得多——但原理相同，SGNS 的 $$k$$ 不宜过大也与此有关（Day 018）。

## 7. 失效案例二：指标饱和与单种子波动

维度消融，3 个种子取平均：

```python
print("维度消融（20 轮，3 种子平均）：")
for d in (2, 5, 10, 20):
    ps, ws_, cs = [], [], []
    for sd in (42, 7, 2024):
        v3, i3, vi3, _ = train_sgns(corpus, d=d, epochs=20, rng_seed=sd)
        p_, w_, c_ = evaluate(v3, i3, vi3)
        ps.append(p_); ws_.append(w_); cs.append(c_)
    print(f"  d={d:>2}: 纯度 = {sum(ps)/3:.4f}，类内 = {sum(ws_)/3:.4f}，"
          f"跨类 = {sum(cs)/3:.4f}，间隔 = {sum(ws_)/3 - sum(cs)/3:.4f}")
```

输出：

```
维度消融（20 轮，3 种子平均）：
  d= 2: 纯度 = 1.0000，类内 = 0.9552，跨类 = -0.1824，间隔 = 1.1376
  d= 5: 纯度 = 1.0000，类内 = 0.9945，跨类 = 0.2802，间隔 = 0.7142
  d=10: 纯度 = 1.0000，类内 = 0.9912，跨类 = 0.3092，间隔 = 0.6820
  d=20: 纯度 = 1.0000，类内 = 0.9827，跨类 = 0.1866，间隔 = 0.7961
```

诚实地说，这张表回答不了"维度选几"：

* **纯度指标饱和**：四个维度全部 1.0——这个任务对纯度太容易（Day 014 平表格的复现：指标没有区分度时，消融在测量指标的无效）；
* **间隔指标波动**：$$d=2$$ 反而间隔最大（1.1376），$$d=5/10/20$$ 在 0.68–0.80 之间无规律起伏——三个种子平均后依然非单调。单次消融的排序很可能是种子噪声（Day 016 就见过 $$d=2$$ 的退化几何，间隔大≠几何健康）；
* **正确的结论写法**："在本语料与指标下，维度在 2–20 之间不构成显著影响因素；确定维度需要更难的任务级评价（相似度数据集、类比任务）与更多种子"——而不是硬挑一个最大的数。

## 8. 边界与工程

* **语料规模的声明**：288 个 Token 的模板语料只为机制验证。真实词向量需要亿级 Token；那里的共现稀疏、模板不存在、多义比例也不同，任何数值结论不可外推；
* **评价的阶梯**：模板纯度（本节）→ 人工近邻抽查 → 公开相似度/类比数据集（word2vec 论文的评价方式）→ 下游任务。越往上越可信也越贵；
* **复现清单**：语料构造代码、全部超参、随机种子、指标定义——四个都齐，别人才能复现你的表。本节已示范（种子 42/7/2024）；
* **与第 5–7 周的衔接**：把"模板语料 + SGNS + 纯度评价"的骨架换成"真实语料 + Transformer + 困惑度/下游指标"，实验流程不变——这就是今天真正练的东西。

## 10. 常见误区

### 误区一：loss 一直降才说明训练健康

本节实测 loss 在几何已正确后反弹三倍。SGNS 的 loss 含负例冲突项，只能作趋势参考；向量质量要用近邻/任务指标判断。

### 误区二：指标满分说明方法验证完毕

纯度 1.0 只说明"这个指标在此语料上没有区分度"。换个更难的评价（类比、相似度数据集），维度与方法差异才会显现。

### 误区三：单种子消融可以选超参

间隔指标在 3 种子平均后仍非单调。没有多种子与显著性意识的消融，选出来的是噪声。

### 误区四：top-K 的 K 随手取

K 必须与"可能的最大命中数"对齐：6 个词、每词 2 个同类，top-2 是唯一不饱和的口径（第 4 节的修正过程就是教训）。

### 误区五：模板语料的结论能外推到真实语料

模板语料是"可控"换"真实"：结论（涌现、簇间多义、早停）是机制层面的；数值（0.99 类内余弦等）只属于这份语料。

## 练习与面试准备

### 30 秒口述题

请在 30 秒内回答：

> 你怎么验证自己训练的词向量是好的？

合格答案应包含：不看 loss 看行为——近邻抽查（分层：高频/低频/多义词）、有条件时用带真值的可控语料测纯度/类间隔、公开相似度与类比数据集、下游任务；加一句"多种子取平均，单次结果不可信"。

### 基础题 1：指标口径

6 个单义词、每个有 2 个同类词。为什么 top-3 纯度必然饱和在 2/3？top-2 的取值范围是什么？

<details>

<summary>参考答案</summary>

候选池里同类词只有 2 个，top-3 的第三个必为异类，命中上限 2/3；top-2 的命中范围 0–2，纯度范围 0–1，才可能区分好坏。指标口径（K 值、候选池）必须显式声明。

</details>

### 基础题 2：解释双义词的位置

苹果到两类的余弦（0.70–0.80）为什么必然低于同类内部的 0.99？

<details>

<summary>参考答案</summary>

苹果的上下文分布是两族模板的并集，被两簇的拉力同时作用，向量只能落在两簇之间的折中位置；而单义词只受本簇拉力，与同类被同样的上下文拉向同一点附近。这与 Day 020 计数分析的"混合向量"是同一现象的学习版。

</details>

### 进阶题 3：负例冲突分析

解释第 6 节 loss 反弹的机制，并给出两个缓解方向。

<details>

<summary>参考答案</summary>

交叉模板使每个类内词都与同一批上下文词共现；对（吃， 苹果）抽到的负例"香蕉"在别处是真实正例，推与拉冲突，分数振荡、loss 抬升。缓解：降低 $$k$$（减少撞上"伪负例"的频率）；或共享负例 batch 内去重/排除同类；根本上是让训练早点停（几何已定）。真实语料共现稀疏，冲突天然温和。

</details>

### 进阶题 4：实验设计审查

同学报告"我的词向量 d=20 显著优于 d=10（间隔 0.80 对 0.68）"。从实验方法上提出至少三条质疑。

<details>

<summary>参考答案</summary>

单种子还是多种子？（本节 3 种子平均后波动 ±0.1 量级，0.12 的差距在噪声带内）；间隔指标在 d=2 时最大但几何退化（Day 016），单一指标是否可信；语料与评价的区分度是否足以支撑"显著"二字；有无报告种子列表与方差。缺任何一条，结论都不成立。

</details>

### 面试追问 5：为什么词向量评价偏好类比/相似度任务而不是 loss

loss 度量的是拟合训练分布的程度（还含负例冲突），不衡量几何是否承载语义；类比任务（a−b+c≈d）直接检验向量空间的代数结构是否对应语义关系，是与训练目标解耦的外部证据。内部指标（loss）与外部指标（任务）必须分开报告。

### 面试追问 6：这个实验怎么升级成"真实感"更强的版本

按阶梯答：语料换真实领域文本（去模板化）；评价换公开相似度数据集 + 人工近邻抽查；训练加 Day 017 的动态窗口与下采样；消融固定多种子协议并报告方差；最后接一个下游任务（如检索召回）作为终极证据。每一步都保留旧配置作回归基线。

### 项目答辩题 7：把本实验讲成一页项目

必备要素与预期追问：配置表（可复现）、指标定义与口径修正过程（top-3→top-2，体现严谨）、三个发现（涌现/簇间多义/早停）各配一条实测数字、两个失效（指标饱和、种子波动）的处置（3 种子协议）、升级路线（真实语料+任务级评价）。追问点通常在"为什么 20 轮停"（答：loss 轨迹+几何不变的对照）与"间隔指标可信吗"（答：不可单独信，需配纯度与任务）。
