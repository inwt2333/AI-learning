# 一日一知

这是我的 AI 技术学习笔记。

学习目标不是快速浏览更多名词，而是每天真正弄懂一个技术细节：能用自己的话解释，能看懂关键代码，能通过实验验证理解。

## 学习范围

- NLP 基础与经典模型
- Transformer 与主流语言模型架构
- LLM 训练、对齐与推理
- 信息检索与 RAG
- Agent、工具调用、规划与可靠性

## 使用方式

1. 按照左侧目录每天学习一个知识点。
2. 先阅读概念和原理，再完成代码实验。
3. 使用笔记模板写出自己的理解，不复制原文。
4. 把笔记交给 Codex 订正。
5. 将订正后的版本加入本书。
