## 1. 从"记得不久"到"训不动"

Day 022 结尾的实验：输入全零、只扰动初始状态，扰动的影响 20 步后归零。当时留了一句话："梯度沿时间回传时同样如此"。今天把这句话变成公式和数字。

训练需要梯度：参数 $$\mathbf{W}_{hh}$$ 出现在**每个**时间步里，损失对它的梯度要把所有步的贡献加起来；而"第 20 步的损失对第 1 步的影响"必须穿过 20 层嵌套的 $$\mathbf{h}_t=\tanh(\mathbf{W}_{hh}\mathbf{h}_{t-1}+\cdots)$$。**前向时信息沿时间衰减多少，反向时学习信号就衰减多少**——同一个 Jacobian 连乘，一个正向用、一个反向用。

## 2. BPTT：链式法则加上时间维

BPTT（Backpropagation Through Time，沿时间反向传播）没有任何新数学：把 RNN 沿时间展开成深度网络（Day 022 的展开图），对它做普通反向传播（Day 019）。"深度"等于序列长度——训练一个 20 步的 RNN，就是在训一个 20 层的网络，且各层共享权重。

```
前向：h_0 → h_1 → h_2 → ... → h_T → loss
反向：loss → ∂L/∂h_T → ∂L/∂h_(T-1) → ... → ∂L/∂h_0
       每过一步，左乘一次 Jacobian ∂h_t/∂h_(t-1)
```

整条回传路的瓶颈是那个连乘：

$$
\frac{\partial\mathbf{h}_T}{\partial\mathbf{h}_0}
=\prod_{t=1}^{T}\frac{\partial\mathbf{h}_t}{\partial\mathbf{h}_{t-1}}
$$

## 3. 单步 Jacobian 与它的推导

对 $$\mathbf{h}_t=\tanh(\mathbf{a}_t)$$，$$\mathbf{a}_t=\mathbf{W}_{xh}\mathbf{x}_t+\mathbf{W}_{hh}\mathbf{h}_{t-1}+\mathbf{b}$$，链式法则分两段：

* $$\partial\mathbf{h}_t/\partial\mathbf{a}_t=\operatorname{diag}(1-\mathbf{h}_t^2)$$：tanh 逐元素求导（$$\tanh'(a)=1-\tanh^2(a)$$），是对角阵；
* $$\partial\mathbf{a}_t/\partial\mathbf{h}_{t-1}=\mathbf{W}_{hh}$$。

相乘得单步 Jacobian：

$$
\frac{\partial\mathbf{h}_t}{\partial\mathbf{h}_{t-1}}
=\operatorname{diag}(1-\mathbf{h}_t^2)\,\mathbf{W}_{hh}
$$

两个因子各藏着一个隐患：

* **tanh 导数 ≤ 1**，且当状态饱和（$$|h|\to1$$）时**趋近 0**——每一步最多原样放行，饱和时几乎掐断；
* **$$\mathbf{W}_{hh}$$ 的谱范数**（最大奇异值，记 $$\lambda$$）在连乘中取幂——$$\lambda^T$$。

于是范数上界大致是 $$\bigl\|\partial\mathbf{h}_T/\partial\mathbf{h}_0\bigr\|\lesssim(\beta\lambda)^T$$（$$\beta$$ 为 tanh 导数平均）。**指数面前无小事**，先建立数感：

| 每步因子 | 50 步后 |
| ------: | ------: |
| 0.99 | ≈ 0.605 |
| 0.9 | ≈ 0.005 |
| 1.02 | ≈ 2.69 |
| 1.1 | ≈ 117.4 |

每步 0.9 的"温和衰减"，50 步就只剩千分之五；每步 1.1 的"温和增长"，50 步放大百倍。$$T$$ 步的连乘没有中间地带——要么消失要么爆炸，这是 RNN 训练困难的第一性原因。

## 4. 实验一：解析 Jacobian 的数值验证

老规矩（Day 019 的方法）：手推的公式先用有限差分核对。构造谱范数精确等于 0.8 的随机矩阵（幂迭代测谱范数后缩放）：

```python
from math import sqrt, tanh
from random import seed, uniform

h_dim = 3


def make_W(target_norm, rng_seed=7):
    """造一个随机矩阵并用幂迭代测谱范数，再缩放到目标范数。"""
    seed(rng_seed)
    W = [[uniform(-1, 1) for _ in range(h_dim)] for _ in range(h_dim)]

    def spectral_norm(M, iters=100):
        # 幂迭代：反复乘单位向量，方向收敛到最大奇异值方向，长度即谱范数。
        v = [1.0 / sqrt(h_dim)] * h_dim
        for _ in range(iters):
            nv = [sum(M[i][j] * v[j] for j in range(h_dim)) for i in range(h_dim)]
            norm = sqrt(sum(x * x for x in nv))
            v = [x / norm for x in nv]
        sv = [sum(M[i][j] * v[j] for j in range(h_dim)) for i in range(h_dim)]
        return sqrt(sum(x * x for x in sv))

    s = spectral_norm(W)
    return [[w / s * target_norm for w in row] for row in W]


def forward(h0, W, b, steps):
    """输入全零，纯靠 h_0 演化 steps 步；收集每步的 h_t（算 tanh' 用）。"""
    states = [list(h0)]
    for _ in range(steps):
        prev = states[-1]
        states.append([
            tanh(b[i] + sum(W[i][j] * prev[j] for j in range(h_dim)))
            for i in range(h_dim)
        ])
    return states


def analytic_jacobian(states, W):
    """∂h_T/∂h_0 = Π_t [ diag(1 - h_t^2) · W ]（沿时间逐步左乘）。"""
    J = [[1.0 if i == j else 0.0 for j in range(h_dim)] for i in range(h_dim)]
    for h_t in states[1:]:
        d = [1 - v * v for v in h_t]  # tanh 在 h_t 处的导数（对角阵）
        step = [[d[i] * W[i][j] for j in range(h_dim)] for i in range(h_dim)]
        J = [
            [sum(step[i][k] * J[k][j] for k in range(h_dim)) for j in range(h_dim)]
            for i in range(h_dim)
        ]
    return J


def numerical_jacobian(h0, W, b, steps, eps=1e-6):
    """中心差分直接算 ∂h_T/∂h_0，用于核对解析公式。"""
    J = [[0.0] * h_dim for _ in range(h_dim)]
    for j in range(h_dim):
        hp = list(h0); hp[j] += eps
        hm = list(h0); hm[j] -= eps
        out_p = forward(hp, W, b, steps)[-1]
        out_m = forward(hm, W, b, steps)[-1]
        for i in range(h_dim):
            J[i][j] = (out_p[i] - out_m[i]) / (2 * eps)
    return J


b = [0.0] * h_dim
h0 = [0.01, -0.01, 0.005]  # 小初始状态：让三种谱范数都从近线性区出发

W_mid = make_W(0.8)
states = forward(h0, W_mid, b, steps=3)
J_a = analytic_jacobian(states, W_mid)
J_n = numerical_jacobian(h0, W_mid, b, steps=3)
dev = max(abs(J_a[i][j] - J_n[i][j]) for i in range(h_dim) for j in range(h_dim))
print("T=3 时解析 vs 数值 Jacobian：")
print(f"  解析 ||J||_F = {sqrt(sum(x*x for row in J_a for x in row)):.6f}")
print(f"  数值 ||J||_F = {sqrt(sum(x*x for row in J_n for x in row)):.6f}")
print(f"  最大元素偏差 = {dev:.2e}")
```

输出：

```
T=3 时解析 vs 数值 Jacobian：
  解析 ||J||_F = 0.612429
  数值 ||J||_F = 0.612429
  最大元素偏差 = 3.96e-13
```

公式与数值在 $$10^{-13}$$ 量级吻合——第 3 节的连乘式可以放心用。

## 5. 实验二：谱范数决定命运

同一初始状态、同一结构，只改 $$\mathbf{W}_{hh}$$ 的谱范数（0.5 / 0.9 / 2.0），看 $$\bigl\|\partial\mathbf{h}_T/\partial\mathbf{h}_0\bigr\|_F$$ 随 $$T$$ 的走势：

```python
def frobenius(M):
    return sqrt(sum(x * x for row in M for x in row))


print("||∂h_T/∂h_0||_F 随 T 的变化（输入全零，同一初始状态）：")
print(f"{'T':>4}{'λ=0.5（消失）':>16}{'λ=0.9（临界）':>16}{'λ=2.0（瞬态爆炸）':>18}")
W_small, W_mid2, W_big = make_W(0.5), make_W(0.9), make_W(2.0)
for T in (1, 2, 5, 8, 12, 20):
    row = []
    for W in (W_small, W_mid2, W_big):
        st = forward(h0, W, b, steps=T)
        row.append(frobenius(analytic_jacobian(st, W)))
    print(f"{T:>4}{row[0]:>16.3e}{row[1]:>16.3e}{row[2]:>18.3e}")

st_big = forward(h0, W_big, b, 20)
print(f"\nλ=2.0 的 max|h_20| = {max(abs(v) for v in st_big[-1]):.4f}（tanh 饱和压制了增长）")
```

输出：

```
||∂h_T/∂h_0||_F 随 T 的变化（输入全零，同一初始状态）：
   T       λ=0.5（消失）       λ=0.9（临界）       λ=2.0（瞬态爆炸）
   1       7.679e-01       1.382e+00         3.071e+00
   2       3.149e-01       1.020e+00         5.035e+00
   5       2.720e-02       5.139e-01         2.764e+01
   8       1.360e-03       1.498e-01         8.761e+01
  12       2.105e-05       2.434e-02         1.496e+02
  20       1.400e-08       1.785e-03         4.682e+01

λ=2.0 的 max|h_20| = 0.9907（tanh 饱和压制了增长）
```

三列三种命运，逐列解读：

* **$$\lambda=0.5$$（消失）**：范数从 0.77 一路缩到 $$1.4\times10^{-8}$$——第 20 步的损失对初始状态的梯度在浮点意义上已经不存在。**学习信号比信息本身死得更快**：Day 022 测的是状态扰动的残余（$$10^{-7}$$ 量级），今天测的是梯度通路的余量，同为指数蒸发；
* **$$\lambda=0.9$$（临界）**：衰减慢了一个数量级，但方向不变——$$T$$ 再大照样消失。"略小于 1"在连乘里没有豁免权；
* **$$\lambda=2.0$$（瞬态爆炸）**：前 12 步范数翻了 50 倍（3.07 → 149.6），随后**掉头向下**——状态被推到饱和区（$$|h_{20}|=0.99$$），tanh 导数趋零，反过来掐死了增长。这是 tanh RNN 的诚实物理：**爆炸是瞬态的**。但真实训练中权重在更新、输入源源不断注入能量，状态反复被拉回线性区，这个瞬态会反复出现——这正是实践中 loss 突然变 NaN 的来源（ReLU 循环网络连这层饱和抑制都没有，爆炸更猛）。

## 6. 长期依赖：梯度到不了的地方学不了

把第 5 节的表格翻译成训练语言。设任务是"句首的词决定句尾的答案"（长期依赖的经典形态）：

* 损失发生在第 $$T$$ 步，关键证据在第 1 步；
* 梯度要从第 $$T$$ 步回到第 1 步相关参数，必须穿过整个连乘；
* $$\lambda=0.5$$ 时这条通路只剩 $$10^{-8}$$——**第 1 步的参数收到的学习信号约等于零**，无论训练多少个 epoch。

所以"RNN 理论上能记住全部历史"（Day 022 的确定性论证）与"梯度下降能教它用上这些历史"是两个命题：前者是前向表达能力，后者是反向可训练性。Bengio 等（1994）证明的正是后者在长距离上的根本困难。解药必须改变**梯度通路本身**——让信息与梯度有一条不衰减的路径。LSTM 的加法状态更新（细胞状态 $$c_t$$ 的直通车道）正是为此设计，明天 Day 024 展开。

## 7. 梯度裁剪：治爆炸的数值手术

爆炸的害处是数值层面的：一步超大梯度把参数甩飞（loss 变 NaN/inf）。Pascanu 等（2013）的标准处置是**按范数裁剪**：

$$
\mathbf{g}\leftarrow\mathbf{g}\cdot\min\left(1,\ \frac{\tau}{\|\mathbf{g}\|}\right)
$$

范数不超过阈值 $$\tau$$ 就原样放行；超过了就整体缩放到 $$\tau$$，**方向不变、幅度封顶**：

```python
def clip(g, threshold):
    """按范数裁剪：超阈值就整体缩到阈值，方向不变。"""
    norm = sqrt(sum(x * x for x in g))
    if norm <= threshold:
        return list(g), norm, 1.0  # 未触发，缩放因子 1
    factor = threshold / norm
    return [x * factor for x in g], norm, factor


# 把 T=8 时 λ=2.0 的整个 Jacobian 摊平当作“梯度向量”（∂L/∂h_0 的 9 个分量）
st8 = forward(h0, W_big, b, 8)
J8 = analytic_jacobian(st8, W_big)
g_explode = [x for row in J8 for x in row]
# 消失情形：λ=0.5、T=20 的同款摊平向量
st20 = forward(h0, W_small, b, 20)
J20 = analytic_jacobian(st20, W_small)
g_vanish = [x for row in J20 for x in row]

print("梯度裁剪（阈值 = 5.0）：")
for name, g in (("爆炸情形(λ=2.0,T=8)", g_explode), ("消失情形(λ=0.5,T=20)", g_vanish)):
    clipped, norm, factor = clip(g, 5.0)
    after = sqrt(sum(x * x for x in clipped))
    print(f"  {name}: 原范数 {norm:.3e} → 裁剪后 {after:.3e}（缩放因子 {factor:.3e}）")
print("裁剪只压超阈值的爆炸；对远低于阈值的消失梯度原样放行（信息无法凭空恢复）")
```

输出：

```
梯度裁剪（阈值 = 5.0）：
  爆炸情形(λ=2.0,T=8): 原范数 8.761e+01 → 裁剪后 5.000e+00（缩放因子 5.707e-02）
  消失情形(λ=0.5,T=20): 原范数 1.400e-08 → 裁剪后 1.400e-08（缩放因子 1.000e+00）
```

一治一不治，原因都在公式里：

* **爆炸**是幅度问题：裁剪保方向、限幅度，参数不会被甩飞——问题解决；
* **消失**是信息问题：梯度范数 $$10^{-8}$$ 远低于任何阈值，裁剪原样放行。就算把阈值设成放大器，方向信息本身已在连乘中被抹平——**丢失的信号无法凭空恢复**。消失只能靠架构（Day 024 门控、残差）解决。

PyTorch 接口是 `torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm)`，在 `loss.backward()` 之后、`optimizer.step()` 之前调用——顺序错了就裁了个寂寞。

## 8. 截断 BPTT 与工程权衡

完整 BPTT 要求整个序列装进计算图：长序列意味着深展开——显存与计算都随 $$T$$ 线性增长。实践折中是**截断 BPTT**（truncated BPTT）：每次只回传 $$k$$ 步（如 20–35），更早的梯度直接放弃；状态 $$\mathbf{h}$$ 仍可跨段携带（前向信息不断，反向学习截断）。

| 截断长度 k | 收益 | 代价 |
| --- | --- | --- |
| 大 | 能学的依赖更长 | 显存/时间大，梯度在长路上仍会衰减 |
| 小 | 训练快、批可更深 | 长于 k 的依赖结构性地学不到 |

其他工程手段的定位：**初始化**（正交初始化让 $$\lambda$$ 起点接近 1）与**合理缩放**能延缓两种病，但不改变连乘本质；**门控**（LSTM/GRU）改变通路本身，是消失的根治方案；**裁剪**只管爆炸。三类手段各管一段，别混用名词。

## 9. 边界与特异性

* **本节实验的边界**：输入全零、固定权重、只看 $$\mathbf{h}_0$$ 通路——这是最干净的隔离实验；真实训练里输入与权重都在变，数字不同、指数规律不变；
* **消失/爆炸与任务长度**：依赖距离越长（段落级 vs 相邻词），消失的伤害越大；短依赖任务里简单 RNN 依然可用；
* **与 Attention 的关系**：Transformer 用注意力直连任意两个位置，梯度不必逐跳传递——这是它统治长序列的结构性原因之一（Day 029 起）；残差连接（Day 037）同样是"给梯度修直道"；
* **诊断经验**：loss 变 NaN 先怀疑爆炸（查梯度范数日志、加裁剪）；loss 降但远距离任务指标不动，先怀疑消失（不是再训久一点）。

## 10. 常见误区

### 误区一：梯度消失和爆炸是同一个问题的两面

机制同为连乘，但处置完全不同：爆炸是数值病，裁剪即愈；消失是信息病，只有改架构。说"用裁剪解决梯度消失"是面试硬伤。

### 误区二：调小学习率能治消失

学习率在梯度**已经算出来之后**才起作用；$$10^{-8}$$ 的梯度乘多大的学习率都到不了远处。调小 lr 只对爆炸的震荡有一点缓解。

### 误区三：初始化能根治

正交初始化让开局 $$\lambda\approx1$$，但训练更新会把权重推离这一点；它买时间，不买痊愈。

### 误区四：截断 BPTT 是为了让梯度更好

截断是**放弃**远距离梯度换成本，不是改善它。长于 $$k$$ 的依赖在截断设置下结构性地学不到。

### 误区五：tanh 饱和只有坏处

饱和的 tanh 导数趋零加剧消失，但同时也压制了爆炸（第 5 节 $$\lambda=2.0$$ 列的掉头）。同一机制两面性，报数字时要一起讲。

### 误区六：Transformer 完全没有长程梯度问题

注意力直连缓解了逐跳衰减，但深层网络仍有自己的优化困难（Pre-Norm/Post-Norm 之争，Day 037）。"缓解"不等于"没有"。

每步因子约 $$0.5\times0.8=0.4$$，上界 $$\approx0.4^{20}\approx1.1\times10^{-8}$$。即使"每步只衰减到 0.4 倍"听起来温和，20 步连乘后学习信号在数值上已经不存在。

</details>

### 基础题 2：数感

计算 $$0.99^{50}$$、$$0.9^{50}$$、$$1.02^{50}$$、$$1.1^{50}$$，并说明对选择 $$\mathbf{W}_{hh}$$ 初始化的启示。

<details>
<summary>参考答案</summary>

$$\approx0.605$$、$$\approx0.00515$$、$$\approx2.69$$、$$\approx117.4$$。启示：谱范数必须控制在 1 附近的一窄带里，稍偏即指数灾难——这是正交初始化（让奇异值集中在 1）的动机。

</details>

### 进阶题 3：推导单步 Jacobian

从 $$\mathbf{h}_t=\tanh(\mathbf{W}_{hh}\mathbf{h}_{t-1}+\mathbf{W}_{xh}\mathbf{x}_t+\mathbf{b})$$ 出发，推导 $$\partial\mathbf{h}_t/\partial\mathbf{h}_{t-1}$$，并说明 $$\mathbf{W}_{xh}\mathbf{x}_t$$ 项为何不出现在结果里。

<details>
<summary>参考答案</summary>

设 $$\mathbf{a}_t=\mathbf{W}_{hh}\mathbf{h}_{t-1}+\mathbf{W}_{xh}\mathbf{x}_t+\mathbf{b}$$，则 $$\partial\mathbf{a}_t/\partial\mathbf{h}_{t-1}=\mathbf{W}_{hh}$$，$$\partial\mathbf{h}_t/\partial\mathbf{a}_t=\operatorname{diag}(1-\mathbf{h}_t^2)$$，链式相乘即得。$$\mathbf{W}_{xh}\mathbf{x}_t$$ 对 $$\mathbf{h}_{t-1}$$ 是常数（这一步的输入不依赖上一步状态），偏导为 0——但注意它**影响 $$\mathbf{h}_t$$ 的取值**，从而通过 $$\operatorname{diag}(1-\mathbf{h}_t^2)$$ 的饱和程度间接影响 Jacobian 大小。

</details>

### 进阶题 4：代码审查

下面的训练循环有什么问题？

```python
loss.backward()
optimizer.step()
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

<details>
<summary>参考答案</summary>

裁剪在 `optimizer.step()` **之后**：参数已经按未裁剪的（可能爆炸的）梯度更新了，NaN 已经发生；而且 step() 之后梯度还在，裁剪只影响下一轮——但下一轮 backward() 会覆盖。正确顺序是 backward() → clip → step()。

</details>

### 面试追问 5：为什么裁剪保方向

裁剪对梯度向量做**等比例缩放**（不改变任何分量的相对大小），只把长度压到阈值内。方向携带"该往哪走"的信息，幅度只决定"这一步迈多大"——训练最怕丢方向，最不怕砍幅度。

### 面试追问 6：截断 BPTT 的 k 怎么选

由任务的典型依赖长度决定下限（k 必须覆盖你想学的依赖），由显存与吞吐决定上限；两者冲突时说明该换架构（门控、注意力）而不是硬截。经验值 20–35 是字符/词级语言模型的常见起点，最终以远距离评测指标验证。

### 项目答辩题 7：RNN 训练中 loss 变 NaN 的排查

答题要点：先定位（打印每步梯度范数日志，二分定位是哪个 batch/哪一步开始爆炸）；立即止血（梯度裁剪 $$\tau$$ 常取 1–5，检查是否在 step 前调用）；查放大源（$$\mathbf{W}_{hh}$$ 初始化谱范数、学习率、是否混入 fp16 溢出）；对照第 5 节的数感表解释为什么"loss 正常下降时也要留着裁剪"——瞬态爆炸随时可能复发；最后补一个"裁剪触发率"监控（多少比例的 step 触发了裁剪），它本身就是训练健康度的信号。
