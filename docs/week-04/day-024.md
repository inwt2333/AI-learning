## 1. 解药的形状：给梯度修直道

Day 023 的病根在一处：状态更新是**乘法嵌套**的 $$\mathbf{h}_t=\tanh(\mathbf{W}_{hh}\mathbf{h}_{t-1}+\cdots)$$，梯度回传每步都左乘 $$\operatorname{diag}(1-\mathbf{h}^2)\mathbf{W}_{hh}$$——tanh 导数压一遍、$$\mathbf{W}_{hh}$$ 乘一遍，指数衰减无法避免。

结构解药的方向因此很明确：**让状态里有一条以"加法"为主的更新路径**。加法在求导时产生常数 1——$$\partial(a+b)/\partial a=1$$——梯度经过它不缩放。LSTM（Long Short-Term Memory，1997）把这条思路做到了极致：一条几乎只做加法的**细胞状态传送带**，配三个可学习的阀门控制"写入、保留、读出"。

## 2. LSTM：传送带与三个门

一步 LSTM 的全部方程（$$\odot$$ 为逐元素乘，$$\sigma$$ 为 sigmoid）：

$$
\mathbf{f}_t=\sigma(\mathbf{W}_f\mathbf{x}_t+\mathbf{U}_f\mathbf{h}_{t-1}+\mathbf{b}_f)
$$

$$
\mathbf{i}_t=\sigma(\mathbf{W}_i\mathbf{x}_t+\mathbf{U}_i\mathbf{h}_{t-1}+\mathbf{b}_i)
$$

$$
\mathbf{g}_t=\tanh(\mathbf{W}_g\mathbf{x}_t+\mathbf{U}_g\mathbf{h}_{t-1}+\mathbf{b}_g)
$$

$$
\mathbf{o}_t=\sigma(\mathbf{W}_o\mathbf{x}_t+\mathbf{U}_o\mathbf{h}_{t-1}+\mathbf{b}_o)
$$

$$
\mathbf{c}_t=\mathbf{f}_t\odot\mathbf{c}_{t-1}+\mathbf{i}_t\odot\mathbf{g}_t
$$

$$
\mathbf{h}_t=\mathbf{o}_t\odot\tanh(\mathbf{c}_t)
$$

数据流一图看全：

```
            ┌─────────── 细胞状态传送带（以加法为主）───────────┐
            │                                                  │
 c_(t-1) ──×──(遗忘门 f：保留多少旧的)──＋── c_t ──tanh──×──(输出门 o)── h_t
            │                        ↑              ↑        │
            │      候选 g ──×──(输入门 i：写入多少新的)        │
            │                        ↑                       │
            └────── h_(t-1) 反馈进三个门（与 x_t 一起）◄───────┘
```

各角色分工：

* **$$\mathbf{c}_t$$（cell state，细胞状态）**：真正的长期记忆。更新式只有"乘一个保留系数 + 加一段新内容"——没有 $$\mathbf{W}_{hh}$$ 的嵌套；
* **$$\mathbf{f}_t$$（遗忘门）**：逐维决定旧记忆保留多少，$$\sigma$$ 输出 0..1——接近 1 全保留、接近 0 清空；
* **$$\mathbf{i}_t$$（输入门）**：候选内容 $$\mathbf{g}_t$$ 写入多少；
* **$$\mathbf{g}_t$$（候选）**：本步"想记什么"，tanh 给出 $$(-1,1)$$ 的内容；
* **$$\mathbf{o}_t$$（输出门）**：记忆读出多少进 $$\mathbf{h}_t$$——$$\mathbf{h}$$ 是给外部（输出头、下一步的门）看的视图，**记忆本体是 $$\mathbf{c}$$**。

门的输出不是概率，是 0..1 的**插值系数**（软开关）。每步 4 组变换（$$f,i,g,o$$），参数量约为简单 RNN 的 4 倍。

## 3. 为什么它治消失：c 通路的 Jacobian

对 $$\mathbf{c}_t=\mathbf{f}_t\odot\mathbf{c}_{t-1}+\mathbf{i}_t\odot\mathbf{g}_t$$ 求 $$\mathbf{c}_{t-1}$$ 的偏导（把门近似视为常数——教材标准分析）：

$$
\frac{\partial\mathbf{c}_t}{\partial\mathbf{c}_{t-1}}=\operatorname{diag}(\mathbf{f}_t)
$$

与 Day 023 的 $$\operatorname{diag}(1-\mathbf{h}_t^2)\mathbf{W}_{hh}$$ 逐项对比：

| | tanh RNN | LSTM 的 c 通路 |
| --- | --- | --- |
| tanh 导数因子 | 有（饱和时 →0） | 无 |
| $$\mathbf{W}_{hh}$$ 乘法 | 有（谱范数取幂） | 无 |
| 每步剩下什么 | $$\operatorname{diag}(1-\mathbf{h}^2)\mathbf{W}_{hh}$$ | $$\operatorname{diag}(\mathbf{f}_t)$$（可学到 ≈1） |

连乘变成 $$\prod_t\operatorname{diag}(\mathbf{f}_t)$$：**门 $$f_t$$ 是网络自己学的**——任务需要长记忆时，梯度下降会把 $$f$$ 推近 1，梯度近似无衰减地流过几十上百步。原论文称之为"常数误差传送带"（constant error carousel）。这不是消灭连乘，是把"每步乘多少"从固定结构**交给学习决定**。

## 4. Python 实现：LSTM 单元逐步执行

```python
from math import exp, sqrt, tanh
from random import seed, uniform

h_dim = 3
d = 2


def sigmoid(x):
    return 1 / (1 + exp(-x))


def lstm_params(rng_seed=42, scale=0.4):
    """LSTM 的四组参数（i/f/g/o 各一套 W、U、b）。"""
    seed(rng_seed)
    params = {}
    for name in ("i", "f", "g", "o"):
        params[name] = {
            "W": [[uniform(-scale, scale) for _ in range(d)] for _ in range(h_dim)],
            "U": [[uniform(-scale, scale) for _ in range(h_dim)] for _ in range(h_dim)],
            "b": [0.0] * h_dim,
        }
    return params


def lstm_step(x_t, h_prev, c_prev, P):
    """一步 LSTM：三个 sigmoid 门 + 一个 tanh 候选；c 加法更新，h 受门控读出。"""
    def gate(name, act):
        p = P[name]
        s = []
        for i in range(h_dim):
            acc = p["b"][i]
            acc += sum(p["W"][i][j] * x_t[j] for j in range(d))     # 输入的贡献
            acc += sum(p["U"][i][j] * h_prev[j] for j in range(h_dim))  # 上一步 h 的反馈
            s.append(act(acc))
        return s

    i_t = gate("i", sigmoid)          # 输入门：多少新信息写入
    f_t = gate("f", sigmoid)          # 遗忘门：多少旧记忆保留
    g_t = gate("g", tanh)             # 候选内容
    o_t = gate("o", sigmoid)          # 输出门：多少记忆读出
    c_t = [f_t[k] * c_prev[k] + i_t[k] * g_t[k] for k in range(h_dim)]
    h_t = [o_t[k] * tanh(c_t[k]) for k in range(h_dim)]
    return h_t, c_t, {"i": i_t, "f": f_t, "g": g_t, "o": o_t}


P = lstm_params()
x_t = [0.5, -0.3]
h, c = [0.0] * h_dim, [0.1, -0.1, 0.0]
print("LSTM 逐步执行（输入固定）：")
for t in range(1, 4):
    h, c, gates = lstm_step(x_t, h, c, P)
    print(f"  t={t}: f={[round(v,3) for v in gates['f']]} i={[round(v,3) for v in gates['i']]}")
    print(f"       c_{t}={[round(v,4) for v in c]}  h_{t}={[round(v,4) for v in h]}")
```

## 5. 实验：梯度高速路与遗忘门偏置

沿 c 通路测 $$\bigl\|\partial\mathbf{c}_T/\partial\mathbf{c}_0\bigr\|_F$$（直接通路，解析值为 $$\prod_t\operatorname{diag}(f_t)$$），对照两组遗忘门偏置与 Day 023 的 tanh RNN：

```python
def lstm_c_run(c0, steps, P):
    """输入全零：纯看细胞状态通路的演化（h 跟着 c 变，再反馈进门）。"""
    h, c = [0.0] * h_dim, list(c0)
    fs = []
    for _ in range(steps):
        h, c, gates = lstm_step([0.0] * d, h, c, P)
        fs.append(gates["f"])
    return c, fs


def c_jacobian_norm(P, steps):
    """c 通路 Jacobian = Π diag(f_t)：解析值（对角阵的 Frobenius 范数）。"""
    _, fs = lstm_c_run([0.0] * h_dim, steps, P)
    prod = [1.0] * h_dim
    for f_t in fs:
        prod = [prod[k] * f_t[k] for k in range(h_dim)]
    return sqrt(sum(p * p for p in prod))


def c_jacobian_numerical(P, steps, eps=1e-6):
    """中心差分核对：∂c_T/∂c_0 的 Frobenius 范数。"""
    J2 = 0.0
    for j in range(h_dim):
        cp = [0.0] * h_dim; cp[j] += eps
        cm = [0.0] * h_dim; cm[j] -= eps
        out_p, _ = lstm_c_run(cp, steps, P)
        out_m, _ = lstm_c_run(cm, steps, P)
        col = [(a - b) / (2 * eps) for a, b in zip(out_p, out_m)]
        J2 += sum(x * x for x in col)
    return sqrt(J2)


# 遗忘门偏置两种设定：0（f 起步 ≈ 0.5）与 4（f 起步 ≈ 0.982）
P_zero = lstm_params()
P_bias4 = lstm_params()
for i in range(h_dim):
    P_bias4["f"]["b"][i] = 4.0

# T=1 时门还不依赖 c_0（h_0 给定），直接通路公式应精确成立
print("c 通路解析 vs 数值（b_f=4，T=1，门与 c_0 无关，公式应精确）：")
print(f"  解析 {c_jacobian_norm(P_bias4, 1):.6f} vs 数值 {c_jacobian_numerical(P_bias4, 1):.6f}")
print("（T=5：解析 1.582 只算直接通路；完整 Jacobian 含经 h_(t-1) 的间接路径，数值 1.792）")


def rnn_jacobian_norm(target_norm, steps, rng_seed=7):
    """简单 RNN 的对照（Day 023 的方法压缩版）。"""
    seed(rng_seed)
    W = [[uniform(-1, 1) for _ in range(h_dim)] for _ in range(h_dim)]
    v = [1 / sqrt(h_dim)] * h_dim
    for _ in range(60):  # 幂迭代求谱范数并缩放
        nv = [sum(W[i][j] * v[j] for j in range(h_dim)) for i in range(h_dim)]
        n = sqrt(sum(x * x for x in nv)); v = [x / n for x in nv]
    sv = sqrt(sum(x * x for x in [sum(W[i][j] * v[j] for j in range(h_dim)) for i in range(h_dim)]))
    W = [[w / sv * target_norm for w in row] for row in W]
    states = [[0.01, -0.01, 0.005]]
    for _ in range(steps):
        states.append([tanh(sum(W[i][j] * states[-1][j] for j in range(h_dim))) for i in range(h_dim)])
    J = [[float(i == j) for j in range(h_dim)] for i in range(h_dim)]
    for h_t in states[1:]:
        step = [[(1 - h_t[i] ** 2) * W[i][j] for j in range(h_dim)] for i in range(h_dim)]
        J = [[sum(step[i][k] * J[k][j] for k in range(h_dim)) for j in range(h_dim)] for i in range(h_dim)]
    return sqrt(sum(x * x for row in J for x in row))


print("\n||∂c_T/∂c_0||_F 对比（LSTM 两种遗忘门偏置 + Day 023 的 tanh RNN λ=0.5）：")
print(f"{'T':>4}{'LSTM b_f=0':>14}{'LSTM b_f=4':>14}{'tanh RNN λ=0.5':>16}")
for T in (1, 5, 10, 20):
    print(f"{T:>4}{c_jacobian_norm(P_zero, T):>14.3e}{c_jacobian_norm(P_bias4, T):>14.3e}"
          f"{rnn_jacobian_norm(0.5, T):>16.3e}")
```

```

  解析 1.700898 vs 数值 1.700898
```

三列读出三层结论：

* **公式经数值验证**：$$T=1$$ 时门与 $$c_0$$ 无关，解析与差分逐位一致（1.700898）。$$T>1$$ 时完整 Jacobian 还含经 $$h_{t-1}$$ 反馈的间接路径（$$T{=}5$$ 时 1.582 对 1.792），本表按教材惯例只统计直接通路——它占主导；
* **$$b_f=4$$ 一列是"高速路"**：$$f\approx0.982$$，20 步后梯度通量还有 1.205（$$\approx0.98^{20}\times\sqrt3$$）——对照 tanh RNN 的 $$9.9\times10^{-6}$$，差了五个数量级。这就是门控的结构意义；
* **$$b_f=0$$ 一列解释了一条工程惯例**：零偏置让 $$f$$ 起步于 0.5，传送带每步漏一半（20 步剩 $$1.65\times10^{-6}$$，和 RNN 一样惨）。所以实践里**遗忘门偏置初始化为 1–2**（让 $$f$$ 起步接近 1），这不是玄学，是本表左列与中列的差距。训练开始后 $$f$$ 交还给学习去调。

## 6. GRU：两个门的简化

GRU（Gated Recurrent Unit，Cho 等 2014）保留"加法路径"的思想，砍掉独立的细胞状态，把三门并成两门：

$$
\mathbf{z}_t=\sigma(\mathbf{W}_z\mathbf{x}_t+\mathbf{U}_z\mathbf{h}_{t-1}+\mathbf{b}_z)
$$

$$
\mathbf{r}_t=\sigma(\mathbf{W}_r\mathbf{x}_t+\mathbf{U}_r\mathbf{h}_{t-1}+\mathbf{b}_r)
$$

$$
\tilde{\mathbf{h}}_t=\tanh(\mathbf{W}_h\mathbf{x}_t+\mathbf{U}_h(\mathbf{r}_t\odot\mathbf{h}_{t-1})+\mathbf{b}_h)
$$

$$
\mathbf{h}_t=(1-\mathbf{z}_t)\odot\mathbf{h}_{t-1}+\mathbf{z}_t\odot\tilde{\mathbf{h}}_t
$$

分工：**更新门 $$z$$** 决定"新候选与旧状态的凸组合"（$$z=0$$ 完全保留旧状态——加法直道就在这一项里）；**重置门 $$r$$** 裁剪旧状态进入候选的方式（$$r\to0$$ 时候选只看新输入，相当于"算了，重想"）。

```python
def gru_params(rng_seed=7, scale=0.4):
    seed(rng_seed)
    params = {}
    for name in ("z", "r", "h"):
        params[name] = {
            "W": [[uniform(-scale, scale) for _ in range(d)] for _ in range(h_dim)],
            "U": [[uniform(-scale, scale) for _ in range(h_dim)] for _ in range(h_dim)],
            "b": [0.0] * h_dim,
        }
    return params


def gru_step(x_t, h_prev, P):
    """一步 GRU：更新门 z 决定“新旧凸组合”，重置门 r 裁剪旧状态进入候选。"""
    def pre(name):
        p = P[name]
        return [
            p["b"][i]
            + sum(p["W"][i][j] * x_t[j] for j in range(d))
            + sum(p["U"][i][j] * h_prev[j] for j in range(h_dim))
            for i in range(h_dim)
        ]

    z = [sigmoid(v) for v in pre("z")]
    r = [sigmoid(v) for v in pre("r")]
    p_h = P["h"]
    cand = []
    for i in range(h_dim):
        acc = p_h["b"][i] + sum(p_h["W"][i][j] * x_t[j] for j in range(d))
        acc += sum(p_h["U"][i][k] * (r[k] * h_prev[k]) for k in range(h_dim))
        cand.append(tanh(acc))
    h_t = [(1 - z[k]) * h_prev[k] + z[k] * cand[k] for k in range(h_dim)]
    return h_t, {"z": z, "r": r, "cand": cand}


Pg = gru_params()
h = [0.0] * h_dim
print("GRU 逐步执行（输入固定）：")
for t in range(1, 4):
    h, gates = gru_step(x_t, h, Pg)
    print(f"  t={t}: z={[round(v,3) for v in gates['z']]} r={[round(v,3) for v in gates['r']]}")
    print(f"       h_{t}={[round(v,4) for v in h]}")

d2, h2 = 256, 512
rnn_p = h2 * d2 + h2 * h2 + h2
print(f"\n参数量（d=256, h=512，单偏置约定）：")
print(f"  RNN {rnn_p:,} | GRU {3 * rnn_p:,} | LSTM {4 * rnn_p:,}")
```

**LSTM vs GRU 怎么选**：

| 维度 | LSTM | GRU |
| --- | --- | --- |
| 门 | 3 个（f/i/o） | 2 个（z/r） |
| 记忆 | 独立细胞状态 c（读写分离） | h 身兼记忆与输出 |
| 参数/计算 | 4 组 | 3 组 |
| 经验 | 表达力略强、历史更久 | 更快、小数据更不易过拟合 |

两者在大量任务上差距很小，属于"都行、靠验证集定"的量级——面试里答出结构性差异比报"谁更强"得分。

## 7. torch 对照

`nn.LSTM` 返回三元组：`output`（每步的 $$h$$）、`h_n`（末步 $$h$$）、`c_n`（末步 $$c$$）。取内部参数手工重放（权重按 $$[i,f,g,o]$$ 四段堆叠）：

```python
import torch

torch.manual_seed(0)
lstm_t = torch.nn.LSTM(input_size=d, hidden_size=h_dim, batch_first=True)
x_seq = torch.tensor([[[0.5, -0.2], [0.1, 0.8], [-0.6, 0.3]]])
out, (h_n, c_n) = lstm_t(x_seq)
print(f"torch LSTM 形状：out {tuple(out.shape)}，h_n {tuple(h_n.shape)}，c_n {tuple(c_n.shape)}")

W_ih = lstm_t.weight_ih_l0   # (4h, d)，行序 [i, f, g, o]
W_hh = lstm_t.weight_hh_l0   # (4h, h)
b_ih, b_hh = lstm_t.bias_ih_l0, lstm_t.bias_hh_l0

h_m = torch.zeros(h_dim)
c_m = torch.zeros(h_dim)
for t in range(3):
    gates = W_ih @ x_seq[0, t] + b_ih + W_hh @ h_m + b_hh  # (4h,) 一次算出四组门
    i_t = torch.sigmoid(gates[0:h_dim])
    f_t = torch.sigmoid(gates[h_dim:2 * h_dim])
    g_t = torch.tanh(gates[2 * h_dim:3 * h_dim])
    o_t = torch.sigmoid(gates[3 * h_dim:4 * h_dim])
    c_m = f_t * c_m + i_t * g_t
    h_m = o_t * torch.tanh(c_m)

print(f"手工重放 vs torch：h 最大偏差 = {(h_m - h_n[0, 0]).abs().max().item():.2e}，"
      f"c 最大偏差 = {(c_m - c_n[0, 0]).abs().max().item():.2e}")
```

输出：

```
torch LSTM 形状：out (1, 3, 3)，h_n (1, 1, 3)，c_n (1, 1, 3)
手工重放 vs torch：h 最大偏差 = 2.24e-08，c 最大偏差 = 2.24e-08
```

偏差 $$2.24\times10^{-8}$$ 为浮点舍入量级（融合算子的求和顺序不同；Day 022 的 RNN 无此差异是因为它没有四段堆叠）。四段拼接的权重布局（`weight_ih_l0` 是 $$4h\times d$$）也顺带立住：**LSTM 一个单元 = 四个并行变换拼成的大矩阵乘**——GPU 友好正是这么来的。

## 8. 边界与工程

* **门控不是万能**：它给了梯度一条"可学的直道"，但超长依赖（千步以上）、层级信用分配仍是难题；Transformer 的注意力直连（Day 029）在长序列上另辟蹊径；
* **代价**：参数与计算约为简单 RNN 的 4 倍（GRU 3 倍）；小数据集上多出的容量可能过拟合；
* **流式与端侧的现代价值**：LSTM 的状态是固定大小的 $$O(h)$$——流式语音、端侧设备、超长在线序列里，它比每步都要带着全部 KV Cache 的 Transformer（Day 072）省得多。门控循环网络没有"过时"，只是退到它更合适的位置；
* **变体一句话**：peephole（让门直接看 $$c$$）、coupled gate（把 $$f,i$$ 合并成 $$1-i$$）都是 LSTM 的小改动；GRU 本身就可以看作"耦合输入/遗忘门 + 去掉输出门"的 LSTM 变体。

## 9. 常见误区

### 误区一：门控彻底解决了梯度消失

它提供了一条**可学的**近恒等路径（$$f\to1$$ 时梯度近无损），但门也可以学成小值（主动遗忘无关信息时本来就该这样）；间接路径、超长距离、深堆叠下仍会出现衰减。缓解 ≠ 消灭。

### 误区二：h_t 是 LSTM 的记忆

记忆本体是细胞状态 $$\mathbf{c}$$（传送带）；$$\mathbf{h}$$ 只是经输出门读出的视图。跨段传状态时要传 $$(\mathbf{h},\mathbf{c})$$ 两个。

### 误区三：GRU 是 LSTM 的等价压缩

结构近似、功能相近，但不等价：GRU 没有独立的 $$c$$、没有输出门、读写不分离。说"简化版"可以，说"等价"错。

### 误区四：门的 sigmoid 输出是概率

0..1 的值是**逐维插值系数**（软开关），不是"该门以多大概率开启"的概率陈述。

### 误区五：遗忘门偏置随便初始化

零偏置让 $$f$$ 起步于 0.5，长期记忆每步漏一半（第 5 节左列的 $$10^{-6}$$）。惯例把 $$b_f$$ 初始化为 1–2，是让传送带开局就"默认保留"。

### 误区六：LSTM 一定比 GRU 好

多数任务两者差距在噪声范围内；GRU 更省、小数据更稳。选择应由验证集与预算决定。

## 练习与面试准备

### 30 秒口述题

请在 30 秒内回答：

> LSTM 为什么能缓解梯度消失？

合格答案应包含：细胞状态 $$c_t$$ 以加法更新 $$f_t\odot c_{t-1}+i_t\odot g_t$$；c 通路 Jacobian 是 $$\operatorname{diag}(f_t)$$，没有 $$\mathbf{W}_{hh}$$ 连乘与 tanh 导数压制；$$f$$ 可学到接近 1，梯度近似无衰减地长距离流动（常数误差传送带）。

### 基础题 1：手算一步 LSTM

单维（$$h=1$$）某步：$$f=0.98$$、$$i=0.5$$、$$g=\tanh(1)\approx0.7616$$、$$o=1.0$$，$$c_0=1.0$$。计算 $$c_1$$ 与 $$h_1$$。

<details>
<summary>参考答案</summary>

$$c_1=0.98\times1.0+0.5\times0.7616=0.98+0.3808=1.3608$$；$$h_1=1.0\times\tanh(1.3608)\approx0.8770$$（tanh(1.3608) 程序核对值 0.8770）。注意加法项让 $$c$$ 突破 1——$$c$$ 不受 tanh 约束，tanh 只在读出时压。

</details>

### 基础题 2：参数量

$$d=300$$、$$h=512$$（单偏置约定）。计算 RNN、GRU、LSTM 的骨干参数量。

<details>
<summary>参考答案</summary>

每组 $$=512\times300+512\times512+512=153600+262144+512=416256$$。RNN 一组 416,256；GRU 三组 1,248,768；LSTM 四组 1,665,024。参数比 1:3:4，与门组数一致。

</details>

### 进阶题 3：推导 c 通路 Jacobian

从 $$\mathbf{c}_t=\mathbf{f}_t\odot\mathbf{c}_{t-1}+\mathbf{i}_t\odot\mathbf{g}_t$$ 出发，在"门视为常数"的近似下推导 $$\partial\mathbf{c}_t/\partial\mathbf{c}_{t-1}$$，并说明该近似何时精确成立。

<details>
<summary>参考答案</summary>

逐维 $$c_{t,k}=f_{t,k}\,c_{t-1,k}+i_{t,k}\,g_{t,k}$$，对 $$c_{t-1,k}$$ 求导（$$f,i,g$$ 视为常数）得 $$f_{t,k}$$，故 Jacobian 为 $$\operatorname{diag}(\mathbf{f}_t)$$。$$T=1$$ 且 $$h_0$$ 给定时精确成立（门只依赖 $$x,h_{t-1}$$，不依赖 $$c$$）；$$T>1$$ 时门经 $$h_{t-1}=o_{t-1}\odot\tanh(c_{t-1})$$ 间接依赖 $$c$$，完整 Jacobian 多出间接项（本节实测 $$T{=}5$$：1.582 直接 vs 1.792 完整）。

</details>

### 进阶题 4：代码审查

下面的 LSTM 实现有什么问题？

```python
f = tanh(Wf @ x + Uf @ h_prev + bf)
c = f * c_prev + i * g
h = tanh(c)          # 读出
```

<details>
<summary>参考答案</summary>

遗忘门用了 tanh：输出在 $$(-1,1)$$ 且可为负——"保留 -0.7 倍旧记忆"没有意义，门必须是 sigmoid 的 0..1 插值；读出丢了输出门 $$o$$，$$h=\tanh(c)$$ 让记忆无条件全量暴露。两处都破坏门控语义。

</details>

### 面试追问 5：遗忘门偏置为什么要初始化成 1–2

$$\sigma(0)=0.5$$：每步保留一半，$$0.5^{20}\approx10^{-6}$$，长期信号开局就死（本节左列实测）；$$b_f=2$$ 时 $$f\approx0.88$$，$$b_f=4$$ 时 $$\approx0.982$$，20 步后梯度通量仍在原量的七成（中列实测）。初始化的任务是"别让结构在起跑线就丢信息"，训练之后门值交还学习。

### 面试追问 6：什么时候还选 LSTM/GRU 而不是 Transformer

强因果流式（语音、在线传感）：循环网络状态固定 $$O(h)$$，逐步成本恒定，而自注意力的 KV Cache 随长度线性增长（Day 072）；端侧小模型预算受限；序列短且依赖局部。反过来：长文档、需要全局直连、可离线并行训练时 Transformer 占优。

### 项目答辩题 7：流式 ASR 编码器的选型答辩

答题要点：明确约束（逐帧到达、延迟预算、设备算力）；给基线（小型 GRU/LSTM：参数量、每帧 FLOPs、实测字错率与延迟）；对照方案（流式注意力/Conformer：质量提升多少、KV/状态内存随时长增长曲线）；说明为何门控循环在此场景是合理取舍（常数内存、因果天然成立）；留下升级路径与触发条件（若词错率差距 >X% 且内存预算允许则迁移）。
