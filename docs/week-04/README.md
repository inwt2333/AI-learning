## 概念速查

一行一个概念：定义与公式压缩自本周讲义，公式为纯文本写法；点"详见"直达对应讲次。

| 概念 | 关键定义 | 公式 / 数量关系 | 详见 |
| ---- | -------- | -------------- | ---- |
| RNN 单元 | 每步把"当前输入 + 上一步隐藏状态"压缩成新的隐藏状态；tanh 把每一维压到 -1..1 | `h_t = tanh(W_xh·x_t + W_hh·h_(t-1) + b_h)`；输出头 `logits_t = W_hy·h_t + b_y` | [Day 022](day-022.md) |
| 参数共享 | 同一组参数在每个时间步复用，参数量不随序列长度增长 | 参数量 = h×d + h×h + h + V×h + V | [Day 022](day-022.md) |
| 隐藏状态 | h_t 是 x_1..x_t 的确定性摘要函数（权重固定时重跑轨迹完全相同） | 形状：x_t 为 d 维、h_t 为 h 维；批处理下 torch 返回 output (B,T,h) 与 h_n (层数,B,h) | [Day 022](day-022.md) |
| 记忆衰减（预告） | 初始隐藏状态的扰动影响随步数指数衰减，长期依赖因此困难 | 实测：扰动影响 0.2498（T=1）→ 0.000000（T=20） | [Day 022](day-022.md) |
| BPTT | 展开成 T 层共享权重的网络后做普通反向传播；回传路逐步左乘单步 Jacobian | `∂h_T/∂h_0 = Π_t diag(1 - h_t²)·W_hh`（解析 = 有限差分，偏差 3.96e-13） | [Day 023](day-023.md) |
| 梯度消失与爆炸 | 谱范数 λ < 1 时连乘指数衰减（学习信号死亡）；λ > 1 瞬态指数增长（NaN） | 实测 λ=0.5：0.768 → 1.4e-8（T=20）；λ=2.0：3.07 → 149.6（T=12）后被 tanh 饱和压制；数感 0.9^50 ≈ 0.005、1.1^50 ≈ 117 | [Day 023](day-023.md) |
| 梯度裁剪 | 超阈值整体等比缩放：保方向、限幅度；治爆炸不治消失 | `g ← g·min(1, τ/‖g‖)`；实测爆炸 87.61 → 5.0，消失 1.4e-8 原样放行；顺序 backward → clip → step | [Day 023](day-023.md) |
| 截断 BPTT | 每次只回传 k 步：成本与依赖长度的折中（长于 k 的依赖学不到） | — | [Day 023](day-023.md) |

## 横向对比

### 梯度消失 vs 梯度爆炸（Day 023）

| 维度 | 消失 | 爆炸 |
| ---- | ---- | ---- |
| 根源 | W_hh 谱范数 < 1（或 tanh 饱和）连乘衰减 | 谱范数 > 1 的瞬态连乘增长 |
| 症状 | 远距离依赖学不到，loss 降但长程指标不动 | loss 突然变 NaN/inf |
| 处置 | 架构级：门控加法路径（Day 024）、残差（Day 037） | 数值级：梯度裁剪 |
| 裁剪效果 | 无效（范数远低于阈值，原样放行） | 立即生效（保方向、封幅度） |

### N-gram 截断历史 vs RNN 压缩历史（Day 008、022）

| 维度 | N-gram 语言模型 | RNN |
| ---- | --------------- | --- |
| 历史表示 | 固定窗口的最后 n-1 个 Token | 固定维度的隐藏状态 h_t 摘要全部历史 |
| 参数量 | 随阶数增长，需要每个上下文独立计数 | 参数共享，不随序列长度增长 |
| 长期依赖 | 超出窗口立即遗忘 | 理论上可携带，实测影响随距离指数衰减（Day 023 展开） |
