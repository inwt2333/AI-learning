## 1. 从丢弃顺序到压缩历史

先盘点此前的模型对"顺序"和"历史"做了什么：

* 词袋 / TF-IDF / BM25（Day 011–014）：完全丢弃顺序；
* Word2Vec（Day 016–018）：只看窗口内共现，顺序信息在"中心—上下文"的配对里丢失大半；
* N-gram 语言模型（Day 008）：条件于**最后 $$n-1$$ 个 Token**——窗口之外的历史被一刀切断。

语言模型的本意（Day 008 的链式法则）要求条件于**全部**历史。N-gram 的窗口是无奈的近似：窗口大了参数组合爆炸（Day 009 的 $$|V|^n$$），窗口小了远处的依赖全部丢失。

RNN（Recurrent Neural Network，循环神经网络；Elman 1990 的原始版本叫 Simple Recrecurrent Network）换了一条路：**不保存历史本身，保存历史的摘要**。用一个固定维度的向量 $$h_t$$（隐藏状态，hidden state）滚雪球——每读入一个新输入，就把"旧摘要 + 新输入"压缩成"新摘要"。摘要维度不随序列变长而变大，这就是"压缩历史"。

## 2. RNN 单元：每一步的计算

一个时间步的全部计算只有两行：

$$
\mathbf{h}_t=\tanh(\mathbf{W}_{xh}\mathbf{x}_t+\mathbf{W}_{hh}\mathbf{h}_{t-1}+\mathbf{b}_h)
$$

$$
\mathbf{y}_t=\mathbf{W}_{hy}\mathbf{h}_t+\mathbf{b}_y
$$

第一行是**状态更新**，第二行是**输出头**（做语言模型时接 softmax 得到词表分布，Day 019 的机制原样适用）。形状清单（$$d$$ 输入维、$$h$$ 隐藏维、$$V$$ 词表）：

| 张量 | 形状 | 含义 |
| --- | --- | --- |
| x_t | d | 当前步输入（如 Token 的 Embedding） |
| h_t | h | 隐藏状态（固定大小，不随 T 增长） |
| W_xh | h × d | 输入到隐藏的变换 |
| W_hh | h × h | 隐藏到隐藏的循环变换（"记忆"所在） |
| b_h | h | 隐藏偏置 |
| W_hy | V × h | 隐藏到输出的变换（输出头） |
| b_y | V | 输出偏置 |

两个细节先立住：

* **tanh 的角色**：把每一维压进 $$(-1,1)$$，状态不会无限放大，且处处有梯度（对比阶跃函数）；
* **$$\mathbf{h}_0$$**：序列开始前的初始状态，惯例取全零向量（第 6 节会实验它的存在感）。

## 3. 展开、参数共享与隐藏状态的意义

沿时间展开（unroll）一个 4 步序列，数据流是：

```
x_1 ─→ [h_1 = tanh(W_xh·x_1 + W_hh·h_0 + b)] ─→ [h_2 = tanh(W_xh·x_2 + W_hh·h_1 + b)] ─→ [h_3 ...] ─→ [h_4 ...] ─→ logits = W_hy·h_4
                 ↑ W_xh, W_hh 在每一步都是同一组参数（参数共享）
h_0 = 0（初始状态）
```

三个结构性结论：

**参数共享。** $$\mathbf{W}_{xh}$$、$$\mathbf{W}_{hh}$$、$$\mathbf{b}_h$$ 在**每个时间步都是同一组**。参数量是 $$h\times d+h\times h+h$$（加输出头 $$V\times h+V$$），**与序列长度无关**——对比 N-gram 每加一阶就多一批独立的条件概率表，这是结构性的节省。

**$$h_t$$ 是前缀的确定性函数。** 权重固定时，$$h_t=f(x_1,\ldots,x_t)$$（对 $$t$$ 归纳即得）：每一步的状态由"初始状态 + 到目前为止的全部输入"唯一决定。重跑同一序列，隐藏轨迹逐位相同——这不是偶然，是定义。

**$$h_t$$ 为什么叫"摘要"。** 它的每一维都是被 tanh 压缩过的加权和：既装着 $$x_t$$ 的当下信息，也通过 $$\mathbf{W}_{hh}\mathbf{h}_{t-1}$$ 装着历史的残余。至于历史能"残余"多久——第 6 节用实验预告答案（spoiler：不乐观，这正是 Day 023 的主题）。

## 4. Python 实现：手工展开

纯 Python 逐行落实第 2 节的公式，$$d=2$$、$$h=3$$、$$V=5$$：

```python
from math import sqrt, tanh
from random import seed, uniform

d, h, V = 2, 3, 5  # 输入维度、隐藏维度、词表大小（输出头）

seed(42)
scale = 0.4
W_xh = [[uniform(-scale, scale) for _ in range(d)] for _ in range(h)]  # h×d
W_hh = [[uniform(-scale, scale) for _ in range(h)] for _ in range(h)]  # h×h
b_h = [0.0] * h
W_hy = [[uniform(-scale, scale) for _ in range(h)] for _ in range(V)]  # V×h
b_y = [0.0] * V


def rnn_step(x_t, h_prev):
    """单步：h_t = tanh(W_xh·x_t + W_hh·h_prev + b)。"""
    new_h = []
    for i in range(h):
        s = b_h[i]
        s += sum(W_xh[i][j] * x_t[j] for j in range(d))    # 当前输入的贡献
        s += sum(W_hh[i][j] * h_prev[j] for j in range(h)) # 上一步状态的贡献
        new_h.append(tanh(s))
    return new_h


def logits_from(h_t):
    """输出头：logits = W_hy·h_t + b_y（接 softmax 才是概率，Day 019）。"""
    return [b_y[v] + sum(W_hy[v][i] * h_t[i] for i in range(h)) for v in range(V)]


# 一个 4 步的迷你序列：每步一个 2 维输入（可想象成 Token 的 Embedding）
sequence = [[1.0, 0.0], [0.0, 1.0], [1.0, 1.0], [0.5, -0.5]]

print("形状清单：")
print(f"  x_t: {d} 维 | h_t: {h} 维 | W_xh: {h}×{d} | W_hh: {h}×{h} | W_hy: {V}×{h}")

h_t = [0.0] * h  # h_0 = 全零（惯例）
for t, x_t in enumerate(sequence, start=1):
    h_t = rnn_step(x_t, h_t)
    print(f"t={t}: x={x_t} → h_{t} = [{', '.join(f'{v:+.4f}' for v in h_t)}]")

print(f"\nh_4 的范围检查（tanh 输出必在 -1..1）：{min(h_t):.4f} ≤ h ≤ {max(h_t):.4f}")
lg = logits_from(h_t)
print(f"末步 logits（{V} 维）：[{', '.join(f'{v:+.4f}' for v in lg)}]")

# 确定性：同一序列再跑一遍，隐藏轨迹应完全相同（h_t 是前缀的函数）
h_again = [0.0] * h
for x_t in sequence:
    h_again = rnn_step(x_t, h_again)
print(f"重跑一致性：{h_again == h_t}")
```

输出：

```
形状清单：
  x_t: 2 维 | h_t: 3 维 | W_xh: 3×2 | W_hh: 3×3 | W_hy: 5×3
t=1: x=[1.0, 0.0] → h_1 = [+0.1111, -0.1781, +0.1870]
t=2: x=[0.0, 1.0] → h_2 = [-0.2895, -0.2187, +0.1631]
t=3: x=[1.0, 1.0] → h_3 = [-0.2887, -0.2379, +0.4718]
t=4: x=[0.5, -0.5] → h_4 = [+0.2015, +0.1828, +0.2423]

h_4 的范围检查（tanh 输出必在 -1..1）：0.1828 ≤ h ≤ 0.2423
末步 logits（5 维）：[-0.0163, +0.0370, -0.0582, -0.0291, +0.0059]
重跑一致性：True
```

读输出的三个要点：每一步 $$h$$ 都在**同一个 3 维空间**里更新（形状不变）；tanh 压住了范围；`重跑一致性：True` 印证第 3 节"$$h_t$$ 是前缀的确定性函数"。

## 5. torch 对照与批处理形状

真实工程里没人手写这个循环——`torch.nn.RNN` 就是它。关键是确认"框架没有魔法"，并把批处理形状搞清（torch 2.7.1 实测）：

```python
import torch

torch.manual_seed(0)
rnn = torch.nn.RNN(input_size=d, hidden_size=h, batch_first=True)
x = torch.tensor([[[0.5, -0.2], [0.1, 0.8], [-0.6, 0.3]]])  # B=1, T=3, d=2
output, h_n = rnn(x)
print(f"torch 形状：output {tuple(output.shape)}（B,T,h），h_n {tuple(h_n.shape)}（层数,B,h）")

# 取出模块内部参数，用第 2 节的公式手工重放一遍
W_ih = rnn.weight_ih_l0   # (h, d)：即公式的 W_xh
W_hh = rnn.weight_hh_l0   # (h, h)
b_ih = rnn.bias_ih_l0     # (h,)
b_hh = rnn.bias_hh_l0     # (h,)

h_manual = torch.zeros(h)
manual_states = []
for t in range(3):
    # torch 的公式：h_t = tanh(W_ih·x_t + b_ih + W_hh·h_(t-1) + b_hh)
    # 偏置拆成两份（输入侧 + 循环侧），求和后与单一 b_h 等价。
    h_manual = torch.tanh(W_ih @ x[0, t] + b_ih + W_hh @ h_manual + b_hh)
    manual_states.append(h_manual)

diff = (output[0] - torch.stack(manual_states)).abs().max().item()
diff_last = (h_n[0, 0] - manual_states[-1]).abs().max().item()
print(f"手工重放 vs torch output 最大偏差 = {diff:.2e}")
print(f"h_n vs 手工 h_3 最大偏差 = {diff_last:.2e}")
```

输出：

```
torch 形状：output (1, 3, 3)（B,T,h），h_n (1, 1, 3)（层数,B,h）
手工重放 vs torch output 最大偏差 = 0.00e+00
h_n vs 手工 h_3 最大偏差 = 0.00e+00
```

偏差为**零**：`nn.RNN` 的每一步就是第 2 节那两行公式（偏置拆成输入侧与循环侧两份，和不变）。批处理形状规则一并立住：

* 输入 `x`：$$(B, T, d)$$——`batch_first=True` 时；**默认是 $$(T,B,d)$$**，忘了设这个参数是最常见的形状事故；
* `output`：$$(B, T, h)$$——**每个时间步**的隐藏状态（做逐 Token 预测时用它的每一步）；
* `h_n`：$$(\text{层数},B,h)$$——**最后一步**的隐藏状态（把状态传给解码器或下一段时用它）。

`output[:, -1, :]` 与 `h_n` 在单层时数值相同，但语义不同：一个是"最后位置的那格输出"，一个是"带走的状态"——多堆叠几层后两者就分道扬镳了。

## 6. 隐藏状态能记多久：一个预告实验

第 3 节说 $$h_t$$ 摘要了全部历史——但摘要的"保真度"随距离衰减吗？做一个最干净的实验：输入全零，只在**初始状态**上做一个扰动，看它对 $$h_T$$ 的影响随 $$T$$ 怎么变化：

```python
seed(7)
h_dim = 4
W = [[uniform(-0.5, 0.5) / sqrt(h_dim) for _ in range(h_dim)] for _ in range(h_dim)]
b = [0.1] * h_dim


def run_hidden(T, h0):
    """输入全零时，纯看 h_0 对 h_T 的影响（W_hh 是唯一的传递通道）。"""
    state = list(h0)
    for _ in range(T):
        state = [
            tanh(b[i] + sum(W[i][j] * state[j] for j in range(h_dim)))
            for i in range(h_dim)
        ]
    return state


zero = [0.0] * h_dim
perturbed = [1.0] + [0.0] * (h_dim - 1)  # 只扰动第一个维度
print("初始隐藏扰动的残余影响（输入全零）：")
for T in (1, 2, 5, 10, 20):
    delta = sqrt(sum((a - c) ** 2 for a, c in zip(run_hidden(T, perturbed), run_hidden(T, zero))))
    print(f"  T={T:>2}: ||h_T(h_0=e_1) - h_T(0)|| = {delta:.6f}")
```

输出：

```
初始隐藏扰动的残余影响（输入全零）：
  T= 1: ||h_T(h_0=e_1) - h_T(0)|| = 0.249798
  T= 2: ||h_T(h_0=e_1) - h_T(0)|| = 0.105106
  T= 5: ||h_T(h_0=e_1) - h_T(0)|| = 0.006541
  T=10: ||h_T(h_0=e_1) - h_T(0)|| = 0.000066
  T=20: ||h_T(h_0=e_1) - h_T(0)|| = 0.000000
```

初始状态的信息**指数式蒸发**：1 步后剩 0.25，5 步后只剩 0.007，20 步后浮点意义上归零。这不是本实验特有的不幸——$$\mathbf{W}_{hh}$$ 连乘加上 tanh 的压缩，系统性地抹掉远距离信息；梯度沿时间回传时同样如此（这正是"梯度消失"）。**"理论上携带全部历史"与"实际上记得住几十步"是两回事**——完整分析（BPTT、梯度消失与爆炸、长期依赖）就是明天 Day 023。

## 7. 边界与工程

* **隐藏维度的选择**：$$h$$ 是容量预算——太小装不下结构，太大训练慢且容易过拟合；没有理论公式，靠验证集选（第 3 周的调参纪律不变）；
* **序列截断与状态传递**：长文档常切成定长片段训练。片段边界要不要把 $$h$$ 接着传（stateful）取决于任务是否真的跨段依赖，须显式决定并记录；
* **形状检查清单**（调试第一步）：输入 $$(B,T,d)$$？`batch_first` 设了吗？`output` 要逐步还是只要末步？`h_n` 的层数维会不会和你手里的层数错位？四个问题过一遍，大半形状事故当场现形；
* **速度**：逐时间步的 Python/Python 级循环无法并行化——同一批内不同长度要填充对齐（Day 006 的 PAD 约定回归），且无法像 Transformer 那样在时间维并行。这是 RNN 在工程上被 Transformer 取代的直接原因之一（Day 029 详述）。

## 8. 常见误区

### 误区一：每个时间步用不同的权重

参数共享是定义的一部分：$$\mathbf{W}_{xh}$$、$$\mathbf{W}_{hh}$$ 全程同一组。"展开图上画了很多箭头"不等于"有很多参数"。

### 误区二：隐藏状态随序列变长而变大

$$h_t\in\mathbb{R}^h$$ 固定维度，变长的只是"展开的步数"。这是"压缩历史"的本意。

### 误区三：output 和 h_n 是同一个东西的两种写法

`output` 是**每一步**的隐藏状态 $$(B,T,h)$$，`h_n` 是**最后一步**（且带层数维）。单层末位置数值相同纯属巧合，多层即分离。

### 误区四：RNN 就是语言模型

RNN 只是骨干。语言模型 = RNN + 输出头 + 训练目标（Day 008 的概率链 + Day 019 的交叉熵）。今天只建了骨干。

### 误区五：h_t 在 LSTM 里就是记忆

LSTM 的"记忆"是专门的细胞状态 $$c_t$$，$$h_t$$ 只是它的输出视图——门控结构是 Day 024 的内容，先把简单 RNN 的 $$h_t$$ 记牢。

### 误区六：不设 batch_first 只是把形状换了个顺序

默认 $$(T,B,d)$$ 下，喂 $$(B,T,d)$$ 的张量不会报错——维度对得上时它会被**静默地错误解释**，训练照跑、结果全错。这是 RNN 工程的头号暗坑。

### 基础题 1：手算两步

$$d=1$$、$$h=2$$，$$\mathbf{W}_{xh}=\begin{bmatrix}0.5\\0\end{bmatrix}$$，$$\mathbf{W}_{hh}=\mathbf{I}$$，偏置全零，$$\mathbf{h}_0=(0,0)$$。输入 $$x_1=1.0$$、$$x_2=-1.0$$，计算 $$\mathbf{h}_1$$ 与 $$\mathbf{h}_2$$（tanh(0.5) ≈ 0.4621）。

<details>
<summary>参考答案</summary>

$$\mathbf{h}_1=\tanh((0.5,0)^\top\cdot1)=(0.4621,0)$$。第二步输入贡献 $$(-0.5,0)$$，历史贡献 $$\mathbf{h}_1$$，相加得 $$(-0.5+0.4621,0)=(-0.0379,0)$$，$$\mathbf{h}_2=(\tanh(-0.0379),0)\approx(-0.0379,0)$$。注意 $$x_2$$ 的贡献被 $$h_1$$ 的历史**部分抵消**——状态是加法混合，不是覆盖。

</details>

### 进阶题 3：证明确定性

用归纳法证明：权重与 $$\mathbf{h}_0$$ 固定时，$$\mathbf{h}_t$$ 由 $$x_1,\ldots,x_t$$ 唯一决定。

<details>
<summary>参考答案</summary>

归纳基础：$$\mathbf{h}_1=\tanh(\mathbf{W}_{xh}\mathbf{x}_1+\mathbf{W}_{hh}\mathbf{h}_0+\mathbf{b})$$ 由 $$\mathbf{x}_1$$（与固定的 $$\mathbf{h}_0$$、权重）唯一决定。归纳步：若 $$\mathbf{h}_{t-1}$$ 由 $$x_1..x_{t-1}$$ 唯一决定，则 $$\mathbf{h}_t$$ 的表达式只依赖 $$\mathbf{x}_t$$ 与 $$\mathbf{h}_{t-1}$$，二者都被唯一决定，故 $$\mathbf{h}_t$$ 由 $$x_1..x_t$$ 唯一决定。推论：同序列重跑轨迹相同（本节实测 `True`）。

</details>

### 进阶题 4：代码审查

下面的训练片段有什么问题？

```python
rnn = torch.nn.RNN(input_size=64, hidden_size=128)
out, h_n = rnn(x)          # x: (B, T, 64)
loss = criterion(out.view(-1, 128), targets.view(-1))
```

<details>
<summary>参考答案</summary>

没设 `batch_first=True`：`nn.RNN` 默认按 $$(T,B,d)$$ 解释输入，形状能对上的 $$(B,T,64)$$ 会被静默错位（$$T$$ 与 $$B$$ 互换），计算的是错误的时间维。修法：`batch_first=True`，或把输入转置成 $$(T,B,d)$$。另可指出：`criterion` 若是 `CrossEntropyLoss`，`out` 还需先过输出头映射到词表维——128 维隐藏不是 logits。

</details>

### 面试追问 5：output 与 h_n 各在什么场景用

逐 Token 任务（语言模型、序列标注）用 `output` 的每一步 $$(B,T,h)$$ 接输出头；只要"整段读完后带走一个表示"（送解码器、接分类头、跨片段传状态）用 `h_n`。多层时 `h_n` 带层数维，`output` 仍是最后一层的逐步输出。

### 面试追问 6：算一个真实配置的参数量

$$d=300$$（Embedding）、$$h=512$$、$$V=50000$$ 的 RNN 语言模型，骨干加输出头共多少参数？

<details>
<summary>参考答案</summary>

$$512\times300+512\times512+512+50000\times512+50000=153600+262144+512+25600000+50000=26{,}066{,}256\approx2610$$ 万。注意输出头占绝对大头（2560 万）——这个观察直接引向 Day 018 讨论过的大词表瓶颈。

</details>

## 一页回顾

```
动机：N-gram 截断历史（窗口外全忘）
     RNN 压缩历史：固定维度的 h_t 滚动摘要全部输入

单元（每步两行）：
h_t = tanh(W_xh·x_t + W_hh·h_(t-1) + b_h)
logits_t = W_hy·h_t + b_y（输出头，接 Day 019 的 softmax 交叉熵）

形状：x_t: d | h_t: h | W_xh: h×d | W_hh: h×h | W_hy: V×h
批处理（batch_first=True）：
  输入 (B,T,d) → output (B,T,h)（每一步）
              → h_n (层数,B,h)（最后一步）
  默认 batch_first=False 是 (T,B,d) —— 静默错位的头号坑

三个结构性质：
① 参数共享：同一组权重用于所有时间步
   参数量 = h×d + h×h + h + V×h + V，与 T 无关
② h_t 是 x_1..x_t 的确定性函数（重跑轨迹逐位相同，实测 True）
③ tanh 把每维压进 (-1,1)

实测验证：
手工展开 4 步：h 逐位打印，值域合规
torch nn.RNN = 手工重放，偏差 0.00e+00（框架无魔法）

记忆衰减预告（输入全零，扰动 h_0）：
T=1: 0.2498 → T=5: 0.0065 → T=20: 0.000000
初始信息指数蒸发 → 梯度回传同样会消失
“理论携带全部历史 ≠ 实际记得住”（Day 023：BPTT 展开）

调试清单：batch_first / output vs h_n / 标签移位 / 初始 loss ≈ ln V
```
